The `b2b/orders/query` endpoint is the **clawback v1** pattern: query a specific user's orders for a specific product to see whether any have been refunded or charged back. Use for customer-support workflows or targeted reconciliation.

For high-volume ingestion, use [clawback v2 SAS-token feed](/reference/xstore-rest-clawback-v2-sastoken) instead.

## Endpoint

```text
POST https://purchase.mp.microsoft.com/v8.0/b2b/orders/query
```

## Headers

Same as [v9 `publisherQuery`](/reference/xstore-rest-v9-query#headers) but sent to `purchase.mp.microsoft.com`.

## Request body

```json
{
  "userStoreId": "{purchaseUserStoreId}",
  "productId": "9NBLGGH42THS",
  "orderState": ["Refunded", "Chargeback", "Revoked"],
  "startTime": "2024-01-01T00:00:00Z",
  "endTime": "2024-04-01T00:00:00Z"
}
```

### Fields

| Field | Notes |
| --- | --- |
| `userStoreId` | Required. Purchase-service UserStoreId (not the collections variant). |
| `productId` | Required. |
| `orderState` | Optional filter; omit to return all orders. |
| `startTime` / `endTime` | Optional window. |

## Response body

```json
{
  "orders": [
    {
      "orderId": "{guid}",
      "orderState": "Refunded",
      "purchasedDate": "2024-01-15T18:32:44Z",
      "refundedDate": "2024-01-20T10:14:03Z",
      "lineItems": [
        {
          "orderLineItemId": "{guid}",
          "productId": "9NBLGGH42THS",
          "skuId": "0010",
          "quantity": 1,
          "revenueAdjustment": "-4.99"
        }
      ]
    }
  ]
}
```

## Typical customer-support flow

1. Customer contacts support asking about a refund.
2. Agent tool posts to `/b2b/orders/query` with the user's UserStoreId and the product.
3. Response reveals the refund; agent reconciles in-game rewards manually.
