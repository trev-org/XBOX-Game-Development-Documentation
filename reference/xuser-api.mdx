Extended XUser surface, complementing the standard [XUser reference](/reference/xuser).

## Covered here

- Sign-in helpers (`XUserAddAsync`, `XUserAddByIdAsync`).
- Identity queries (`XUserGetGamertag`, `XUserGetId`).
- Privileges and feature gates (`XUserCheckPrivilege`, `XUserResolveIssue`).
- Token acquisition for XSAPI and partner services (`XUserGetTokenAndSignatureAsync`).
- Change-event subscriptions.
