Low-level memory allocation helpers for the GDK. `XMem` lets you allocate memory with explicit attribute hints — alignment, page type, cacheability — useful for graphics and audio scratch buffers.

## Functions

- `XMemAllocDefault` — generic system allocation.
- `XMemFreeDefault` — release memory returned by `XMemAllocDefault`.
- Attribute-based allocator hooks for graphics, audio, and physical memory subsystems.

## When to use XMem

- Large GPU-visible heaps where you want explicit control over physical attributes.
- Audio offload buffers (Shape DMA / XMA / DSP contexts).
- Custom allocators that need to honor platform alignment rules.
