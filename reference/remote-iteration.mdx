Remote iteration lets you push file or asset changes to an XBOX dev kit without rebuilding and redeploying the full package — critical for iteration speed on art, audio, and script content.

## Tools

- **`xbcopy`** — copy files between PC and dev kit.
- **`xbapp`** — launch, suspend, terminate, and manage installed apps.
- **`wdapp`** — PC-side equivalent. For driving a remote PC over the network, see the [XBOX PC Remote Tools](/tools/pc-remote-tools) (`wdRemote`, `wdEndpoint`, `wdCapture`, `wdCaptureSession`).
- **Remote Run** in the [XTF](/reference/xtf) — programmatic remote launch from build scripts.

## Recommended workflow

1. Loose-file your asset directories during development.
2. Mount them on the dev kit so engine reloads pick up changes instantly.
3. Use [WDP REST](/reference/wdp-rest) endpoints to automate the loop in your editor.
