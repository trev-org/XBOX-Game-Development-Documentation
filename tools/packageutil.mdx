**`packageutil.exe`** is the swiss-army knife for packages produced by `makepkg`.

## Verbs

| Verb | Purpose |
| --- | --- |
| `info` | Show identity, layout, signature |
| `verify` | Cryptographic \+ structural check |
| `sign` | Re-sign with a specified cert |
| `extract` | Explode a package back to loose files |
| `repair` | Fix minor structural issues |
