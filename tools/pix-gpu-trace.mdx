**GPU Trace** captures many frames of GPU timing plus hardware counters at low overhead. Use it to find bottlenecks that only appear in real gameplay.

## What it records

- Per-draw GPU busy timing.
- Wavefront occupancy per stage.
- Memory bandwidth (VRAM, L2 hit rate).
- Front-end vs. back-end wait states.
- Shader export bottlenecks.

## Analyze

- Correlate spikes to specific draws.
- Filter by pass or event marker.
- Overlay hardware counters against title-emitted PIX events.
