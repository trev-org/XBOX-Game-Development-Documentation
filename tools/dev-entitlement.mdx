**`DevEntitlementTool.exe`** manages Microsoft Store entitlements for test accounts, so QA can verify DLC, add-ons, and store gating.

## Common commands

```text
DevEntitlementTool grant  --user <gamertag> --productId <id>
DevEntitlementTool revoke --user <gamertag> --productId <id>
DevEntitlementTool list   --user <gamertag>
```

## Notes

- Works only in developer sandboxes.
- Requires signed-in developer account (`XblDevAccount`).
