**Dr. PIX** is an automated checker that runs against a PIX GPU Capture and reports likely correctness bugs.

## Checks

- Uninitialized reads (SRV / UAV read before write).
- Missing depth/RT clear at the start of a pass.
- Resource in wrong state at the point of use.
- Descriptor heap or root signature mismatch.
- Draw calls with zero output (culled or clipped away).
- Sampler state incompatible with texture format.

## Workflow

1. Take a GPU Capture.
2. Open **Dr. PIX** in the capture window.
3. Triage findings by severity.
