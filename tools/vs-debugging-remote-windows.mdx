Remote-Windows debugging pairs Visual Studio with a Windows device (handheld or test PC) that runs the GDK PC runtime. Iteration is over LAN via the [XBOX PC Remote Tools](/tools/pc-remote-tools).

## Setup

1. Install **wdEndpoint** on the remote device.
2. Pair from your dev PC with `wdRemote pair <device>`.
3. Set the VS project remote debugger to the device address.
4. Deploy and F5 as normal.
