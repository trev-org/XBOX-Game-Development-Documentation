Many widely used middleware providers ship GDK-aware SDKs. This page indexes categories — for the current list of certified partners, see [the Partner Center middleware catalog](https://developer.microsoft.com/games/middleware).

## Engines

- **Unreal Engine** — first-class GDK targets for both Xbox and PC.
- **Unity** — GDK build support (PC and Xbox via approved plugins).
- **Godot**, **Stride**, **O3DE** — community-maintained GDK bindings.

## Audio

- Wwise, FMOD.

## Physics

- PhysX, Havok, Jolt.

## Networking

- Photon, EOS, Nakama, Playfab.

## Analytics \+ LiveOps

- PlayFab, GameAnalytics, Unity Gaming Services.

## Anti-cheat \+ security

- EAC, BattlEye, Denuvo.

## Streaming \+ video

- Bink, Theora, NVENC-adjacent tooling for PC.

## Integration guidance

- Prefer middleware SDKs that publish GDK-specific binaries.
- Confirm certification support for both **Xbox One** and **Xbox Series X|S** if you cross-gen.
- Register any third-party auth flows via the [Fiddler](/tools/fiddler-web-calls) and [Trace Analyzer](/tools/trace-analyzer) workflows during integration.
