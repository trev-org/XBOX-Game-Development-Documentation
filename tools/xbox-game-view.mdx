**XBOX Game View** shows the video output of the active dev kit inside a Visual Studio dockable window — so you can watch the title while you have the debugger, System Monitor, and code side by side.

## Open

**View → Other Windows → XBOX Game View**

## Requirements

- [XBOX video server](/tools/xbox-video-server) enabled on the console.
- Gigabit wired connection recommended for stutter-free video.

## Tips

- Right-click the view to record to disk.
- The overlay from [Title Performance Overlay](/tools/title-performance-overlay) is visible in Game View.
