**XBOX System Monitor** is the in-VS live counter view. It provides continuous graphs for the console currently set as the deployment target.

## Metrics

- CPU utilization per core
- GPU busy percentage
- VRAM commit, system RAM commit
- Disk / SSD activity
- Frame time (when a title with PIX markup is running)

## Open

**View → Other Windows → XBOX System Monitor**
