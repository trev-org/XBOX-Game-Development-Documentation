PIX provides HLSL-level shader debugging both in captures and live.

## Modes

| Mode | Data source | Use case |
| --- | --- | --- |
| **Capture debug** | GPU Capture | Post-mortem inspection of a specific draw |
| **On-demand Live** | Attached live GPU | Break at will into any running shader |
| **Live on Shader Exception** | Attached live GPU | Break automatically on div-by-zero, OOB, etc. |
| **Shader Exception Detection in GPU Captures** | GPU Capture | Find exceptions retrospectively |

## Edit and Continue

Edit the HLSL, hit **Recompile**, and PIX re-runs the wavefront on the captured inputs so you can iterate without re-capturing.

## Shader PDBs

Provide a symbol path with the private shader PDBs for source-level stepping. See [Shader PDBs](/tools/pix-shader-pdbs).
