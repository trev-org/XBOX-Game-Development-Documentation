The **XBOX Gaming Explorer** is a Visual Studio tool window that lists every dev kit reachable on the network, along with the packages and processes on each one.

## Open the window

**View → Other Windows → XBOX Gaming Explorer**

## What you can do

- Set the active deployment target.
- Reboot, sync layout, or launch a package.
- Kill a running process.
- Open Device Portal or Dev Home for the selected console.
- Chain-launch multiple consoles in a group.

## Comparison to XBOM

XBOX Manager (XBOM) is the desktop tool for managing many consoles. Gaming Explorer is the in-VS mini-version for quick actions against a single target during iteration.
