The GDK ships two supported C\+\+ toolchains for XBOX targets:

- **MSVC** (default) — the same compiler used for PC, tuned for Zen 2 (Scarlett) and Jaguar (XboxOne).
- **Clang/LLVM** — available on all targets; see [Clang with the GDK](/tools/vs-clang).

## Codegen highlights

- Both toolchains emit AVX2 by default on Scarlett; SSE4.2 on XboxOne.
- Whole-program optimization (LTCG) is on for Release builds.
- [Profile-Guided Optimization](/tools/profile-guided-optimization) is supported end-to-end.

## PDBs

GDK builds emit both a private PDB (full source) and a stripped public PDB. Keep the private PDBs in a symbol store keyed on GUID \+ age.
