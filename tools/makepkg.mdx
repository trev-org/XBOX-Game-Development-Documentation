**`makepkg.exe`** turns a loose GDK layout into a signed package suitable for cert submission or dev-kit install.

## Package types

| Extension | Target |
| --- | --- |
| `.xvc` | XBOX console |
| `.msixvc` | PC via Store install |

## Basic invocation

```text
makepkg pack /d C:\Layouts\MyGame /pd C:\Packages
```

## Common switches

| Switch | Meaning |
| --- | --- |
| `/d` | Source layout directory |
| `/pd` | Package destination directory |
| `/f` | Layout include/exclude filter file |
| `/l` | Localization pack |
| `/gameos` | Target GDK Game OS version |
| `/streaminstall` | Author streaming install chunks |
