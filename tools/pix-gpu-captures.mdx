**GPU Captures** record a single frame's worth of D3D12 activity in full detail. Use them for correctness bugs and per-draw cost.

## Views

- **Events** — tree of PIX events / draw calls.
- **Pipeline** — IA, VS, HS, DS, GS, PS, CS, RS, OM state at the selected event.
- **Resources** — every SRV, UAV, RTV, DSV visible with format and mip.
- **State** — pipeline state object contents.
- **API Objects** — raw ID3D12 object graph.
- **Mesh, Texture, BVH viewers** — inspect draw payloads.

## Debugging

- **Shader debugging** on the captured wavefront.
- **Edit \+ continue** to iterate on a shader without re-capturing.
- **Dr. PIX** correctness checker on the full capture.

## Capture

UI trigger or `PIXBeginCapture(PIX_CAPTURE_GPU, ...)` from title code.
