**`XblDevAccount.exe`** signs in your Partner Center developer account so other XBOX service CLI tools can authenticate.

## Usage

```text
XblDevAccount signin  --user you@company.com
XblDevAccount signout
XblDevAccount whoami
```

Tokens are cached per Windows user profile.
