**XBOX Gaming Project Control** is the guided editor for the GDK project fields you would otherwise edit in `MicrosoftGame.config` by hand.

## Fields covered

- Identity: package name, publisher, version
- Executables list and startup app
- Store category and ContentID
- Localization
- Streaming install layout
- MSAA / render / display / device family capabilities

## Validation

Every field is validated against the schema live — the compile step will not silently drop malformed values.

## Open

Right-click the project → **Properties → XBOX Gaming Project Control**, or **View → Other Windows → XBOX Gaming Project Control**.
