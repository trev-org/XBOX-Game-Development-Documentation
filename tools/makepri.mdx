**`makepri.exe`** builds Package Resource Index (`.pri`) files. GDK titles use PRI for localized strings, images, and scale-factor assets.

## Basic invocation

```text
makepri new /pr C:\Layouts\MyGame\Assets /cf priconfig.xml /of resources.pri
```

## Notes

- Called automatically by `makepkg` when a project references PRI content.
- Regenerate whenever the resource set changes.
