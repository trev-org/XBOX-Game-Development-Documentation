`takx takx-version` prints the installed CLI version. Include this in bug reports and support tickets so your Microsoft Program Representative can match your version to known issues.

## Synopsis

```powershell
takx takx-version
```

## When to use

- Confirm which CLI version is on PATH after an install or upgrade.
- Include the version in bug reports and support requests.
- Verify CI runners have the expected version installed.

<Note>
  This is the CLI version. To print or set the version of the bundle itself, use [`takx version`](/gdk/game-streaming-tak-command-line-version-command).
</Note>
