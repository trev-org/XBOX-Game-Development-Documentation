**Guest users** (also called **Sponsored Guests** or **Guest Accounts**) let players interact with many XBOX services without creating a full XBOX account. They're sponsored by a signed-in XBOX player on the same device.

A Sponsored Guest session ends when the guest signs out, the sponsor signs out, or the device shuts down.

<Note>
  A separate concept called a **Pure Guest** exists for the state where no user is signed in at all. Pure Guests cannot make authenticated XBOX service calls and cannot play games that require a signed-in XBOX user.
</Note>

## Supporting guests

Guest support is optional. Pass `XUserAddOptions::AllowGuests` to `XUserAddAsync`.

```cpp
XUserAddAsync(XUserAddOptions::AllowGuests, asyncBlock);
```

Check if a handle is a guest with `XUserGetIsGuest`.

<Warning>
  Guests have no deterministic identity. Don't store player preferences keyed to a guest.
</Warning>

## Subscription, parental controls, privileges

Guests inherit the sponsor's subscription, parental controls, and community policy enforcement. These privileges are **revoked** for guests:

- `XPRIVILEGE_BROADCAST`
- `XPRIVILEGE_MANAGE_PROFILE_PRIVACY_SETTING`
- `XPRIVILEGE_GAME_DVR`
- `XPRIVILEGE_SOCIAL_NETWORK_SHARING`
- `XPRIVILEGE_ADD_FRIEND`

## Service support matrix

| Area | Guest support |
| --- | --- |
| Cloud Storage | Not supported |
| Authentication / Privacy / Privileges | Inherited from sponsor |
| User Profile | Partial — view public data |
| Multiplayer | Inherited from sponsor |
| Achievements | Not supported |
| Stats | Not supported |
| Custom web service / S2S | Supported |
| Social Manager | Not supported |
| PlayFab Party Chat | Supported via sponsor permissions |

<Warning>
  It is the developer's responsibility to avoid calling unsupported services with a guest handle. Calls to unsupported services typically return `HTTP_E_STATUS_BAD_REQUEST`.
</Warning>

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can multiple guests be signed in simultaneously?">
    Yes. Multiple guests can share the same sponsor and be signed in at the same time.
  </Accordion>

  <Accordion title="Do guests have access to device entitlements?">
    Yes. Device entitlements and installed content propagate to guests just like they do to XBOX users.
  </Accordion>

  <Accordion title="How do guests behave on platforms that don't support them (PC, mobile)?">
    Guest accounts appear as normal accounts with the sponsor's permissions — no additional code required.
  </Accordion>

  <Accordion title="Are guest accounts tested in certification?">
    Guest support is not specifically covered by certification. Supporting guests is optional and up to the developer.
  </Accordion>
</AccordionGroup>
