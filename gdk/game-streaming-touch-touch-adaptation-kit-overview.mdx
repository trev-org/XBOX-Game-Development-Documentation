The **Touch Adaptation Kit (TAK)** is the authoring and packaging toolchain for touch controls on streamed titles. It lets you design, preview, pack, and serve a **Touch Adaptation Bundle (TAB)** that the streaming pipeline delivers to gamepad-less clients so they can play your game with touch.

## When your title needs a TAB

- Any title expected to be reachable by a touch client (phone, tablet, touch-only Web CTA session).
- Any title where the streamed audience is broader than gamepad-only.
- Any title where you want to author touch-specific UX rather than accepting a generic default overlay.

## The end-to-end flow

<Steps>
  <Step title="Author">
    Design your layouts in the [TAK Editor](/gdk/game-streaming-tak-editor) or start from a [template layout](/gdk/game-streaming-tak-command-line-templates).
  </Step>
  <Step title="Preview">
    Preview layouts against a recorded gameplay video in the editor before you pack.
  </Step>
  <Step title="Pack">
    Pack a `.tab` file with the [TAK CLI `pack` command](/gdk/game-streaming-tak-command-line-pack-command) or the editor.
  </Step>
  <Step title="Serve during testing">
    Sideload the bundle to a CTA using the [TAK CLI `serve` command](/gdk/game-streaming-tak-command-line-serve-command).
  </Step>
  <Step title="Publish">
    [Publish the layout](/gdk/game-streaming-touch-publishing-layouts) so the streaming service ships it to real clients.
  </Step>
</Steps>

## Key concepts

| Concept | What it is |
| --- | --- |
| [Touch Adaptation Bundle (TAB)](/gdk/game-streaming-touch-touch-adaptation-bundle) | Packed `.tab` file containing all layouts and assets for one title |
| Layout | One touch overlay tuned for a specific game state |
| Layout state | Which layout is currently active — the title triggers state changes at runtime |
| Template | Genre-based starting layout that the [`create`](/gdk/game-streaming-tak-command-line-create-command) command emits |
| Custom assets | Optional bitmaps replacing the default controls — see [Custom assets](/gdk/game-streaming-tak-custom-assets) |
