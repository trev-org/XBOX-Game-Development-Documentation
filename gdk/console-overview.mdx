The Microsoft Game Development Kit (GDK) exposes a set of features that only exist when your title targets **XBOX console hardware** — XBOX One family and XBOX Series X|S. These give you direct access to specialized subsystems: a multi-tier audio pipeline with spatial sound, a high-throughput NVMe-backed storage stack with DirectStorage, certified networking APIs, hardware raytracing and mesh shaders, Game DVR, and platform behaviors like Quick Resume.

If your title also ships on Windows PC, isolate these features behind a runtime or compile-time platform check. Console-specific APIs either fail to compile or return an error at runtime when called on PC.

## What makes a feature "console-specific"?

A GDK feature is console-specific when it relies on hardware or OS services that only exist on XBOX consoles:

- **Persistent Local Storage (PLS)** — a dedicated, encrypted storage partition pre-allocated on the console SSD before your title launches.
- **DirectStorage** — bypasses the CPU for GPU-direct asset decompression via the Series X|S NVMe controller.
- **Spatial audio** — hardware-accelerated Dolby Atmos decoding through the HDMI audio pipeline.
- **XAppCapture** — deep integration with the system DVR service that manages clip recording across every title on the console.
- **Quick Resume** — multi-title suspend/resume that can pause your title for days.
- **Hardware DXR / mesh shaders / VRS** — GPU capabilities exposed through the Series X|S driver stack.

Windows PC equivalents exist for some of these (for example, DirectStorage on PC), but the console variants have different initialization paths, quotas, and certification requirements.

## Certification requirements

Microsoft enforces XBOX certification requirements (XRs) that apply specifically to console titles. Violating them causes cert failure. Key requirements covered in this section include:

| Requirement | Topic |
| --- | --- |
| XR-133 — Local storage write limitations | [Storage](/gdk/storage) |
| Network security (secure socket usage) | [Networking](/gdk/networking) |
| Game DVR privacy (voice-chat exclusion) | [Game DVR](/gdk/game-dvr) |
| Quick Resume behavior on resume | [Quick Resume](/gdk/quick-resume) |

Review the full [XBOX Certification Requirements](https://learn.microsoft.com/en-us/gaming/gdk/docs/policies/certification/certification-requirements) before submitting your title.
