Cloud Aware API calls let your title know when it is being streamed and adapt to each connected client. The `XGameStreaming` header exposes everything needed to detect a session, register for state changes, and query per-client properties.

## Detect an active stream

<Tip>
  `XGameStreamingIsStreaming` returns a process-wide snapshot. Register for connection state changes as well — players can start a Remote Play session while the title is already running.
</Tip>

```cpp
#include <XGameStreaming.h>

bool IsCurrentlyStreaming()
{
    return XGameStreamingIsStreaming();
}
```

## React to connect / disconnect

Register for connection state changes so you can update UI, pause gameplay, or apply latency-friendly settings the moment a client attaches or detaches.

```cpp
XTaskQueueRegistrationToken token{};

XGameStreamingRegisterConnectionStateChanged(
    m_taskQueue,
    this,
    [](void* context,
       XGameStreamingClientId clientId,
       XGameStreamingConnectionState state)
    {
        auto* game = static_cast<Game*>(context);
        if (state == XGameStreamingConnectionState::Connected)
            game->OnStreamingStarted(clientId);
        else
            game->OnStreamingStopped(clientId);
    },
    &token);
```

## Query per-client properties

Each connected client has its own display, input, and network characteristics. Use per-client properties to tailor UI scale, input prompts, and latency-compensating behavior.

```cpp
uint32_t width  = 0;
uint32_t height = 0;
HRESULT hr = XGameStreamingGetClientDimensions(clientId, &width, &height);

char countryRegion[XGameStreamingCountryRegionMaxBytes] = {};
hr = XGameStreamingGetClientCountryRegion(
    clientId, XGameStreamingCountryRegionMaxBytes, countryRegion, nullptr);

XGameStreamingGamepadPhysicality physicality = {};
hr = XGameStreamingGetGamepadPhysicality(gamepadReading, &physicality);
```

<Warning>
  `XGameStreamingGetClientIPAddress` is deprecated as of the June 2026 (2604) GDK. Use the newer client identity APIs and server-side signals instead.
</Warning>

## Common patterns

<AccordionGroup>
  <Accordion title="Refresh detection on new UI" icon="arrows-rotate">
    Re-check streaming status when you show a new screen. Remote Play and xCloud both support join-in-progress, and a stream can start after the title is already running.
  </Accordion>

  <Accordion title="Match input to client" icon="gamepad">
    `XGameStreamingIsStreaming` is process-wide but client properties are per `XGameStreamingClientId`. When a player picks up a controller, look up the client it maps to so you show the right prompts and touch layout.
  </Accordion>

  <Accordion title="Detect touch versus gamepad" icon="hand-pointer">
    Use `XGameStreamingGetGamepadPhysicality` on each gamepad reading to distinguish physical gamepads from a virtual gamepad generated by a touch layout. Use this to show touch-appropriate prompts — see [Change in-game UI, hints and control remapping for touch controls](/gdk/game-streaming-tak-designers-guide#change-in-game-ui-hints-and-control-remapping-for-touch-controls).
  </Accordion>

  <Accordion title="Pause on disconnect" icon="pause">
    Mobile clients disconnect briefly whenever the player checks messages or answers a call. Pause gameplay when the only active client disconnects to prevent lost progress — see [Common issues for touch controls and Xbox Game Streaming](/gdk/game-streaming-tak-designers-guide#check-for-common-issues-for-touch-controls-and-xbox-game-streaming).
  </Accordion>
</AccordionGroup>
