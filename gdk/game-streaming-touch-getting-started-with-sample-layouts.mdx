The easiest way to create a [Touch Adaptation Bundle](/gdk/game-streaming-touch-touch-adaptation-bundle) is to start from a genre-appropriate sample. The [`takx create`](/gdk/game-streaming-tak-command-line-create-command) command emits ready-to-pack layouts based on a small set of templates.

## Using a sample as a starting point

<Steps>
  <Step title="Emit a template">
    Run:

    ```powershell
    takx create my-title-bundle --template first-person
    ```
  </Step>
  <Step title="Preview against your gameplay">
    Open the layout in the [TAK Editor](/gdk/game-streaming-tak-editor) and preview against a video of your title. Reposition controls to match your ergonomics.
  </Step>
  <Step title="Split into per-state layouts">
    Duplicate the layout for each gameplay state — [changing layouts by game state](/gdk/game-streaming-touch-changing-layouts-game-state) covers the runtime side.
  </Step>
  <Step title="Customize the look">
    Once ergonomics are right, replace default art with [custom assets](/gdk/game-streaming-tak-custom-assets).
  </Step>
</Steps>

<Note>
  The sample layouts are illustrative starting points. Every shipping title should adapt the layout to its own controls, priorities, and visual style rather than shipping a sample verbatim.
</Note>
