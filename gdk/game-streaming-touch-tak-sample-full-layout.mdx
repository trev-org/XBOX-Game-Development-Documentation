A layout that provides a mapping of every physical controller action to a touch control.

## What it is

The standard controller layout provides a touch layout that is most similar to a physical controller.

This layout is meant to be an example of how all the physical actions can be exposed — not as a recommended experience for any particular style of game.

<Warning>
  This layout is not optimized for any game and players will likely have a poor experience playing for any extended period of time with it. Use it as a fallback reference; ship a purpose-built layout for real gameplay.
</Warning>

## When to use it

- As a fallback for gameplay states or menus where a purpose-built layout does not exist yet.
- As a reference when you need to understand which touch primitive maps to each physical control.
- As a starting point when you are prototyping and have not yet designed a genre-specific layout.

## Availability

Part of the TAK [sample-layouts](https://github.com/microsoft/xbox-game-streaming-tools/tree/main/touch-adaptation-kit/samples/sample-layouts) on GitHub. The `takx create` templates do not emit this layout — it exists as a reference sample.
