The **`XSpeechSynthesizer`** API provides support for initializing and configuring a speech synthesis engine (a voice) to convert a text string into an audio stream — also known as text-to-speech (TTS). Voice characteristics, pronunciation, volume, pitch, rate/speed, and emphasis are customized through [Speech Synthesis Markup Language (SSML) Version 1.0](https://www.w3.org/TR/speech-synthesis/).

<Note>
  This API requires callers to use **SSML version 1.0**.
</Note>

## Using the API

<Steps>
  <Step title="Create the synthesizer">
    Call `XSpeechSynthesizerCreate` and hold on to the returned handle for the lifetime of the synthesizer.
  </Step>
  <Step title="Choose a voice (optional)">
    Call either `XSpeechSynthesizerSetCustomVoice` or `XSpeechSynthesizerSetDefaultVoice` to select the voice you want.
  </Step>
  <Step title="For each string, create a stream">
    Call `XSpeechSynthesizerCreateStreamFromText`. When this function returns, conversion of the text to a `.wav` file is already complete.

    <Warning>
      Conversion can take a non-trivial amount of time. **Do not call `XSpeechSynthesizerCreateStreamFromText` on time-critical threads.**
    </Warning>
  </Step>
  <Step title="Query the buffer size">
    Call `XSpeechSynthesizerGetStreamDataSize` to determine the size of the buffer you need for the audio data.
  </Step>
  <Step title="Read the audio data">
    Call `XSpeechSynthesizerGetStreamData` to copy the `.wav` audio data out of the stream, then pass it to an audio renderer.
  </Step>
  <Step title="Close the stream handle">
    Call `XSpeechSynthesizerCloseStreamHandle` when you're done with the current stream. Repeat steps 3–6 for each additional string.
  </Step>
  <Step title="Close the synthesizer handle">
    When you're completely done with speech synthesis, call `XSpeechSynthesizerCloseHandle`.
  </Step>
</Steps>

### Example

```cpp
#include <XSpeechSynthesizer.h>

XSpeechSynthesizerHandle synth = nullptr;
XSpeechSynthesizerCreate(&synth);

// Optional: pick a specific voice.
// XSpeechSynthesizerSetDefaultVoice(synth, ...);

XSpeechSynthesizerStreamHandle stream = nullptr;
XSpeechSynthesizerCreateStreamFromText(synth, "You have unlocked a new ability.", &stream);

size_t byteCount = 0;
XSpeechSynthesizerGetStreamDataSize(stream, &byteCount);

auto buffer = std::make_unique<uint8_t[]>(byteCount);
XSpeechSynthesizerGetStreamData(stream, byteCount, buffer.get(), nullptr);

// Pass 'buffer' (a .wav) to an audio renderer.

XSpeechSynthesizerCloseStreamHandle(stream);
XSpeechSynthesizerCloseHandle(synth);
```
