## First layout in five steps

<Steps>
  <Step title="Create a bundle from a template">
    Run `takx create` and pick the [template](/gdk/game-streaming-tak-command-line-templates) closest to your title's genre — for example `first-person`, `platformer`, or `driving`.

    ```powershell
    takx create my-title-bundle --template first-person
    ```
  </Step>
  <Step title="Preview the layout">
    Open the source folder in the [TAK Editor](/gdk/game-streaming-tak-editor) and preview the layout against a placeholder gameplay video.
  </Step>
  <Step title="Pack the bundle">
    Produce a `.tab` file:

    ```powershell
    takx pack my-title-bundle -o my-title.tab
    ```
  </Step>
  <Step title="Serve it to the CTA">
    Start a local server and point the CTA at it:

    ```powershell
    takx serve my-title.tab
    ```

    Follow the [deploying a touch layout](/gdk/game-streaming-touch-deploying-touch-layout) instructions to sideload from the Web CTA.
  </Step>
  <Step title="Iterate">
    Tweak the layout in the editor, pack, and re-serve until the touch experience feels right in a real stream.
  </Step>
</Steps>
