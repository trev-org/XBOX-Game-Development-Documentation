Download the latest XBOX Game Development Kit (GDK) release and install it on your Windows development PC.

## Prerequisites

- Windows 11 (latest update)
- Visual Studio 2022 with the C\+\+ workload
- Windows 10/11 SDK

See [SDK & tools](/gdk/sdk-and-tools) for the full install matrix.

## Download

Get the GDK and Game Core for XBOX from the [Microsoft GDK download page](https://aka.ms/gdkdl).

## Install

1. Run the GDK installer as Administrator.
2. Accept the license terms.
3. Choose the GDK and (optionally) the Game Core for XBOX components.
4. Wait for the installer to complete and reboot if prompted.

After install, open Visual Studio and verify the **Gaming.Desktop.x64** and **Gaming.Xbox.Scarlett.x64** platforms appear in the Configuration Manager.
