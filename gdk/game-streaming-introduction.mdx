XBOX Game Streaming and XBOX Remote Play let players experience your game on devices that could not otherwise run it — phones, tablets, PCs, and smart TVs. Your title works with streaming out of the box, but the GDK exposes APIs, testing tools, and touch adaptation authoring so you can tailor the streaming experience to each client.

## Two streaming modes

<CardGroup cols={2}>
  <Card title="XBOX Cloud Gaming (xCloud)" icon="cloud" href="/gdk/game-streaming-project-xcloud-vs-console-streaming">
    Your game runs on an XBOX server in a Microsoft Azure datacenter. Players stream from the closest datacenter — no console required.
  </Card>

  <Card title="XBOX Remote Play" icon="house" href="/gdk/game-streaming-project-xcloud-vs-console-streaming">
    Your game runs on the player's own console at home and streams to their Windows PC or mobile device.
  </Card>
</CardGroup>

Both modes are transparent to your game at the rendering and logic level. The GDK `XGameStreaming` APIs let you discover which mode is active and adapt accordingly.

## Supported client platforms

XBOX Game Streaming supports players connecting from:

- Windows PCs via the XBOX app
- iOS and Android phones and tablets via the XBOX app / Game Pass app
- Smart TVs with the XBOX app built in
- Web browsers via [xbox.com/play](https://www.xbox.com/play)

Your game runs identically on the server regardless of client. Client-specific adaptations — touch layouts, display scaling, input remapping — are surfaced through the Cloud Aware APIs.
