GDK titles read input through **GameInput**, the modern device-agnostic input API shared between XBOX and Windows. GameInput replaces XInput and Windows.Gaming.Input for GDK titles and covers every input device a player can plug in.

## Best practices at a glance

- Always handle device hot-plug and re-query on Quick Resume — the active gamepad may have changed.
- Support the XBOX Adaptive Controller for accessibility.
- Poll or use callbacks on a consistent cadence; do not mix polled and event-driven reads in the same frame.
- Version your interfaces — always ask for the highest `IGameInputReadingN` your code understands and fall back gracefully.
- Never bind gameplay to physical scan codes — abstract into engine actions and let the user rebind.
