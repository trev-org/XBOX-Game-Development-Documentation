The **TAK Editor** is the Windows application for authoring [Touch Adaptation Bundles](/gdk/game-streaming-touch-touch-adaptation-bundle). It lets you place controls visually, preview a layout against recorded gameplay video, and pack a ready-to-serve `.tab` file.

## What the TAK Editor is for

<CardGroup cols={2}>
  <Card title="Visual layout authoring" icon="pen-nib">
    Drag controls into position on a canvas that matches your title's target aspect and safe area.
  </Card>

  <Card title="Preview against video" icon="video">
    Load a recorded gameplay clip and overlay your layout to sanity-check reach, occlusion, and visibility.
  </Card>

  <Card title="Multi-layout projects" icon="layer-group">
    Manage every layout in one bundle side-by-side — exploration, combat, inventory, cutscenes.
  </Card>

  <Card title="Pack directly" icon="box">
    Produce a `.tab` file from inside the editor, or drive packing from the [TAK CLI](/gdk/game-streaming-tak-command-line).
  </Card>
</CardGroup>

## When to use the editor vs. the CLI

| Task | Editor | CLI |
| --- | --- | --- |
| Position and tune controls visually | ✅ | – |
| Preview a layout against video | ✅ | – |
| Bulk template generation | – | ✅ (`takx create`) |
| CI packing and verification | – | ✅ (`takx pack`, `takx verify`) |
| Sideload a bundle to the CTA | – | ✅ (`takx serve`) |

Most teams use the editor for design iteration and the CLI for automation.
