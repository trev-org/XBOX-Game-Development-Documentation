The GDK ships with reference samples that demonstrate platform features end-to-end.

## Where to find samples

Samples live in the [Xbox-GDK-Samples GitHub repository](https://github.com/microsoft/Xbox-GDK-Samples) and locally under `%GameDK%\Samples` after install.

## Sample categories

- **Graphics** — raytracing, mesh shaders, variable rate shading (VRS), sampler feedback streaming.
- **System** — async/task queues, packaging, game saves, Persistent Local Storage.
- **Audio** — XAudio2, spatial audio, Game Chat 2.
- **Networking** — PlayFab Party, XCurl, multiplayer.
- **Store** — XStore, in-app purchase, DLC.
- **Live** — XSAPI achievements, social, multiplayer, leaderboards.
