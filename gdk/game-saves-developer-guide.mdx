This guide provides a starting point for integrating Game Saves features into a title. It covers essential terminology, an outline of available APIs, and important considerations such as user models, security, and certification requirements.

## Overview

The following terms appear across the Game Saves ecosystem.

| Term | Definition |
| --- | --- |
| **Game Saves ecosystem** | Previously called _Connected Storage_ or `XGameSave`. Manages how games save data on the device and synchronize that data with the cloud. Data is organized into containers and blobs. |
| **Title** | The game you're developing. |
| **Sandbox** | The environment where your title runs. |
| **Microsoft Partner Center** | The Microsoft web portal that manages your title's configuration and sandbox. |
| **Service configuration identifier (SCID)** | A unique identifier for the service configuration of your title within Xbox services. |
| **Microsoft account (MSA) App ID (MSAAppID)** | Required identifier that links a game to its Microsoft account identity. Generated in Partner Center and placed in `MicrosoftGame.config` so Xbox services can authenticate the title. |

Common service terms used in the Game Saves APIs:

| Term | Definition |
| --- | --- |
| **Local storage** | Data saved during gameplay that's written to the device. |
| **Title storage / cloud** | Storage that automatically synchronizes with title storage in the cloud when the device is connected to the internet. |
| **Lock** | A mechanism that grants exclusive access to a title's Game Saves for a specific user on the device they're actively using. Ensures no other device can modify the Game Saves for that user while the lock is held. |
| **Provider** | The intermediary mechanism that communicates with the Game Save system. Manages game data and the lock for a user on a device. |
| **Container** | Analogous to a folder. |
| **Blob** | Analogous to an individual file. |

## New titles

Before using Game Saves, your title must have Xbox services enabled in Partner Center. This provides a SCID and MSAAppID for your title. For more information, see [Enabling Xbox services and Game Saves for your title](/gdk/game-saves-walkthroughs#enabling-xbox-services-and-game-saves-for-your-title).

After Partner Center is set up, we recommend using [XGameSaveFiles](/gdk/xgamesavefiles) for Game Saves implementation.

## Game Saves APIs

| API | Description | Platforms | Use case | Sample |
| --- | --- | --- | --- | --- |
| [XGameSaveFiles](/gdk/xgamesavefiles) | Provides a file path for Game Saves local storage that automatically syncs to the cloud. | PC, Xbox | Recommended for most scenarios. Provides a file path for you to read/write to that syncs automatically to the cloud. | GameSaveFilesCombo |
| [No-code cloud saves](/gdk/game-saves-walkthroughs#porting-previous-titles-to-pc-game-saves-with-no-code-cloud-saves) | You provide a file path that's automatically synced to the cloud. | PC | Ideal for PC games that can't directly use the GDK or are porting to PC Game Pass. Provides the read/write path in the game .config file. | None |
| [XGameSave](/gdk/game-saves) | Data is saved locally and synced to the cloud. | PC, Xbox | Supports titles that need larger or more complex per-user storage. Offers detailed control of file management. | GameSaveCombo |

## User models

Two user models are supported. We recommend the **Simple User Model**.

| Method | Description | Retail platform differences |
| --- | --- | --- |
| **Simple User Model** | A default user is required and controls the lifetime of the game instance. The OS ensures a user signs in when the game launches. | **PC:** The game terminates when the default user signs out.<br />**Console:** The game suspends when the default user signs out. |
| **Advanced User Model** | No default user. No guarantee that a user is signed in when the game launches. | None |

For more information about user models, see [GDK User Models](/gdk/gamecore-user-models). For best practices on signing users in, see [How to: best practice to sign in a user](/gdk/xuser-howto-best-practice-signing-in).

## Security

### Personal data

Microsoft doesn't offer an API or tool that allows you to access a specific user's Game Saves data. If you need this information to troubleshoot an issue, contact the user directly and ask them to share it.

### Saving securely

<Warning>
  Game Saves aren't secure when PC accessibility is enabled. With PC accessibility, users can open the file path directly, which exposes the saved data. We recommend that you implement your own server-side checks to confirm the appropriate state of a game save.
</Warning>
