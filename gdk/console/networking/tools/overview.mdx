Several tools are available for diagnosing, capturing, and stress-testing networking behavior for GDK titles.

## Capture and inspection

<CardGroup cols={2}>
  <Card title="NetCap" icon="wave-square" href="/gdk/console/networking/tools/netcap">
    Capture network traffic on Xbox consoles using xbtrace, Microsoft Message Analyzer, or Netmon.
  </Card>

  <Card title="Fiddler on PC" icon="filter" href="/gdk/console/networking/tools/fiddler-pc">
    Inspect HTTP/HTTPS traffic from PC titles using Fiddler Classic.
  </Card>

  <Card title="Fiddler on Xbox" icon="filter" href="/gdk/console/networking/tools/fiddler-setup">
    Configure Fiddler as a proxy for Xbox devkits.
  </Card>
</CardGroup>

## Stress testing

<CardGroup cols={2}>
  <Card title="NetStress" icon="gauge-high" href="/gdk/console/networking/tools/netstress">
    Simulate degraded network conditions using xbstress profiles.
  </Card>
</CardGroup>

<Note tag="NDA">
  For simulating full network outages, see [Simulating Network Downtime](https://developer.microsoft.com/gaming/xbox-nda-docs/_content/gc/networking/overviews/tools/netdowntime) on the Xbox NDA docs site.
</Note>
