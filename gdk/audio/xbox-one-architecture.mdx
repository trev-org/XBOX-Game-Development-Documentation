The Xbox One audio subsystem is a layered stack that lets titles work at whatever abstraction level suits them, from high-level XAudio2 all the way down to direct SHAPE / ACP programming.

## Layers

<CardGroup cols={2}>
  <Card title="XAudio2" icon="volume-high" href="/gdk/audio/xaudio2">
    High-level source voices, submix voices, mastering voice, effects, and streaming buffers. Recommended entry point for most titles.
  </Card>

  <Card title="WASAPI" icon="wave-square" href="/gdk/audio/wasapi">
    Raw audio endpoints for capture (headset mic) and low-latency render scenarios such as voice chat and communications.
  </Card>

  <Card title="SHAPE" icon="waveform-lines" href="/gdk/audio/shape">
    Fixed-function hardware audio blocks — XMA decode, sample-rate convert, EQ/compressor, filter/volume, and DMA.
  </Card>

  <Card title="ACP" icon="microchip-ai" href="/gdk/audio/acp">
    Audio Control Processor drives SHAPE via app-authored flowgraphs. Access via the `IACPHAL` interface.
  </Card>
</CardGroup>

## System audio flow

The title's mastering voice is routed by the system to the currently active endpoints — TV/speakers, headset, controller headset, Kinect array (Xbox One), or the game DVR / broadcast pipeline. Titles do not choose the endpoint; the shell manages it based on user configuration.

For capture-side flows, use WASAPI to read the headset mic. For voice chat, use Game Chat (see the Networking section) rather than raw mic streams.

## Series X|S additions

Series X|S adds the **XAPU** (Xbox Audio Processing Unit) providing hardware Opus decode and a high-quality sample rate converter. See [Xbox Series X|S audio hardware](/gdk/audio/scarlett-audio) and [XAPU](/gdk/audio/xapu).
