Sample layout for a first-person shooter.

## Design at a glance

| Element | Placement |
| --- | --- |
| Movement joystick | Left thumb |
| Camera touchpad | Right thumb (relative mouse output) |
| Common action buttons | Arranged around a right-hand wheel |

## Remarks

The first person shooter layout provides all the basic controls needed for a first person shooter style game.

Key elements include:

- A joystick on the left for player movement.
- A touchpad on the right for camera control using relative mouse output.
- Common actions arranged as buttons around the right wheel.

## Availability

1. Part of the TAK [sample-layouts](https://github.com/microsoft/xbox-game-streaming-tools/tree/main/touch-adaptation-kit/samples/sample-layouts) on GitHub.
2. Emitted by the [`takx create` command](/gdk/game-streaming-tak-command-line-create-command) via the `first-person` template.
