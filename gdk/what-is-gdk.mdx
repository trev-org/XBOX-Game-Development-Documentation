The **XBOX Game Development Kit (GDK)** is Microsoft's unified toolchain for building games that target XBOX consoles and Windows PC from a single codebase.

The GDK provides:

- **Gaming Runtime** — the core platform APIs (`XGameRuntime`, `XGameSave`, `XStore`, `XUser`, `XPackage`, ...).
- **Platform Extensions** — console-specific features for XBOX Series X|S and XBOX One.
- **Visual Studio integration** — the `Gaming.Desktop.x64` and `Gaming.Xbox.Scarlett.x64` platforms.
- **Command-line tools** — `makepkg`, `xbapp`, `wdapp`, `SubmissionValidator`, and the MicrosoftGame.config editor.
- **Samples** — reference titles for graphics, audio, networking, and store integration.

The GDK supersedes the legacy XDK and replaces UWP as the recommended way to ship Microsoft Store games.
