Layout for fighting games using a familiar arcade-like arrangement.

## Design at a glance

| Element | Placement |
| --- | --- |
| Directional pad | Larger, on the left — supports precise motion inputs |
| Punch / kick buttons | Arcade-style arrangement on the right |

## Remarks

The fighting layout provides all the basic controls needed for a fighting game.

Key elements include:

- A larger directional pad for movement.
- An arcade-style layout of punch/kick controls.

## Availability

1. Part of the TAK [sample-layouts](https://github.com/microsoft/xbox-game-streaming-tools/tree/main/touch-adaptation-kit/samples/sample-layouts) on GitHub.
2. Emitted by the [`takx create` command](/gdk/game-streaming-tak-command-line-create-command) via the `fighter` template.
