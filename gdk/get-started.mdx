This is **step 2 of the guided path**. You should have completed [ID@XBOX onboarding](/onboarding) before you begin — you cannot download the GDK without it.

By the end of this section you will have Visual Studio, the Windows SDK, and the GDK installed on a properly configured dev PC, and you will have built and run a sample.

## Do these in order

<Steps>
  <Step title="Understand what the GDK is" icon="circle-question">
    Read the GDK overview so you know what you're installing and what shipping on PC vs. XBOX actually means.

    <Card title="What is the GDK?" icon="arrow-right" href="/gdk/what-is-gdk">
      Components, runtime, and relationship to XDK and UWP.
    </Card>
  </Step>
  <Step title="Set up your dev PC" icon="desktop">
    Confirm your machine meets the hardware and OS requirements. Windows 10 (May 2019 Update or later) or Windows 11 is required.

    <Card title="Dev PC setup" icon="arrow-right" href="/gdk/dev-pc-setup">
      Hardware and OS requirements.
    </Card>
  </Step>
  <Step title="Install Visual Studio, the Windows SDK, and the GDK" icon="wrench">
    Install the toolchain in the correct order — Visual Studio first, Windows SDK, then the GDK.

    <Card title="SDK & tools" icon="arrow-right" href="/gdk/sdk-and-tools">
      Install order and version requirements.
    </Card>
  </Step>
  <Step title="Download & install the GDK" icon="download">
    Download the latest GDK release from the secure download site (requires ID@XBOX access) or clone the public GDK on GitHub.

    <Card title="Download & install" icon="arrow-right" href="/gdk/download-install">
      Get the GDK on your machine.
    </Card>
  </Step>
  <Step title="Build a sample" icon="code">
    Open one of the shipped GDK samples in Visual Studio and confirm your environment builds and deploys cleanly. This validates every step above.

    <Card title="GDK samples" icon="arrow-right" href="/gdk/samples">
      Reference samples that ship with the GDK.
    </Card>
  </Step>
</Steps>
