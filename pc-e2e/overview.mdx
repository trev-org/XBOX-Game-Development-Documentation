This guide walks through shipping a Windows PC title end-to-end with the GDK — from engine integration, through XBOX services adoption, to Microsoft Store submission.

## Stages

1. **Choose an engine path** — see [GDK and engines](/pc-e2e/gdk-and-engines).
2. **Integrate the GDK** in your engine — [Unreal](/pc-e2e/engines/unreal), [Unity](/pc-e2e/engines/unity), [GameMaker](/pc-e2e/engines/gamemaker), [Godot](/pc-e2e/engines/godot), or [Custom engine](/pc-e2e/engines/custom-engine).
3. **Adopt optional services** — achievements, multiplayer, cloud saves, PlayFab. See [Optional services](/pc-e2e/optional-services).
4. **Optimize for handhelds** — see [Handheld devices](/pc-e2e/handheld).
5. **Submit to the Microsoft Store** via [Partner Center](/publishing/overview).
