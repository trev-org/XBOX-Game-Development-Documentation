Integrate the GDK and XBOX services into a Unity project targeting Windows PC (and, with the appropriate platform extension, XBOX consoles).

## Integration paths

- **Unity GDK plug-in** — Microsoft-maintained package that bridges XUser, XStore, achievements, and game saves into C#.
- **Native plug-in** — wrap GDK C APIs in a custom managed wrapper for advanced scenarios.

## Setup

1. Install the GDK — see [Download and install](/gdk/download-install).
2. Add the Unity GDK package to your project.
3. Configure `MicrosoftGame.config` — see [Game config](/gdk/game-config).
4. Build and package with the Unity GDK build pipeline or `makepkg`.
