# How to submit royalty tiers

[!INCLUDE [reminder](../includes/managed-creators-only-feature.md)]

Royalty tier declarations define the tier at which royalties will be paid based on your wholesale price (WSP) to final retail for each territory in which you will release physical discs. Royalty tier declarations are required for each edition of the game you will release.

## Submitting royalty tiers in Partner Center

To access Retail Disc Royalty Tier Setup for a product, you must have *Manage Products* or *Royalty Config Setup* permissions in Partner Center. For details about how to configure correct user permissions, see [Set Custom Permissions for Account Users](/windows/apps/publish/partner-center/assign-product-level-custom-permissions-to-account-users).

After you have the correct permissions, select **Discs** - **Royalty Configuration** from your game's navigation menu in Partner Center. 

### Standard Royalty Tier selections 

To select a royalty tier for the majority of physical publishing options, use your Partner Center account. 

 1. Select **Royalty Configuration** under the **Discs** navigation option. If you have multiple types of products configured, select the Game product.
 2. Select **New Royalty Program**, and then complete the form. Include the following:
    - Royalty program name: We recommend including the game name and SKU edition in this field for easy review in the future. For example, “My Game Name - Deluxe Edition”.
    - Sales territory.
    - Wholesale price (WSP): Use the highest WSP to final retail.
    - Royalty program edition: In this case, use Standard. For more information about these options, see the Retail Programs and Tier Selection Guide in the [Xbox Publisher Guide](https://aka.ms/xboxpublisherguide).
    - Royalty tier: This information is determined by the game’s Wholesale Price to Final Retail.
    - The manufacturing number for the first 90 days.
    - In the **Notes** section, restate your highest WSP to final retail.
 3. Select **Submit**.

For more information, see [Submitting Royalty Tiers](../concepts/discs-royalty-configuration.md).

### Non-standard Royalty Tier selections

Before submitting any non-standard edition royalty tiers, we recommend that you share your plans for all non-standard SKUs from your Microsoft contacts. For details, see [SKU Planning](../publishing-processes/managed-creators/publishing-processes-sku-planning.md). Also, be sure to review the latest [Microsoft Advertising Network Policies](https://help.ads.microsoft.com/#apex/ads/en/ext60205) before submitting materials for any non-standard edition.

1. Select **Royalty Configuration** under the **Discs** navigation option. If you have multiple types of products configured, select the Game product.
2. Change the *Royalty Program Edition* to the correct non-standard edition (more guidance is in the *Retail Programs and Tier Selection Guide* available in the [Publisher Guide](https://aka.ms/xboxpublisherguide) (1. Manufacturing & Retail > 2. Retail Programs and Tier Selection Guide)).
3. Complete the rest of the form. Include the following:
    - Royalty program name: we recommend including the game name and SKU edition in this field for easy review in the future. For example, “My Game Name - Deluxe Edition”.
    - Sales territory.
    - Wholesale price (WSP): Use the highest WSP to final retail.
    - Royalty tier: This information is determined by the game’s Wholesale Price to Final Retail.
    - The manufacturing number for the first 90 days.
    - In the **Notes** section, restate your highest WSP to final retail.
5. Select **Submit**.

#### Royalty Tiers for non-standard publishing scenarios

To select a tier for the following publishing scenarios, speak to your Microsoft contacts for assistance. You can't use Partner Center for these scenarios.
 - Sub-Publishing
 - Publishing in China
 - Compilation discs
 - Incentive programs

#### Migration of royalty tiers

Review the Retail Programs and Tier Selection Guide in the [Xbox Publisher Guide](https://aka.ms/xboxpublisherguide) for additional information on eligibility to migrate to a different royalty tier. If you're eligible and you're migrating a royalty tier that's configured in Partner Center, use the following steps.

 1. Select the previously approved tier entry.
 2. Under the Royalty Tier, select a new tier from the dropdown menu.
 3. In the Notes field, specify the info for Previous Tier and New Tier.
 4. Select **Submit.**

## Additional guidance on selecting royalty tiers

For complete guidance on royalty tiers, see the *Retail Programs and Royalty Tier Selection Guide*. This guide is available as a download from the [Publisher Guide](https://aka.ms/xboxpublisherguide).
