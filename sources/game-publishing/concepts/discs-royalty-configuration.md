# Royalty configuration

[!INCLUDE [reminder](../includes/managed-creators-only-feature.md)]

On the **Royalty configuration** page, you can create different royalty programs for your product. A royalty program enables you to sell an edition of a product on physical discs to different territories. For example, you can create a royalty program for the Game of the Year edition of your game that you sell to North America.

## Create a royalty program

1. Navigate to the product overview page, expand **Discs** in the left navigation menu, and select **Royalty Configuration**. This will take you to the **Royalty configuration** page.

2. Select **New royalty program**.

3. Fill out the **Create new royalty program** form.

    a. **Royalty program name**: The nickname for the royalty program.

    b. **Sales territories**: The area where you will sell copies of your product for this royalty program. Choose from the following territories:

    * **Asia**
    * **Australia**
    * **Europe**
    * **Japan**
    * **North America**
    * **South America**

    c. **Wholesale price (anticipated)**: The amount of money you plan to make on each sale. This should be in the currency listed, which changes based on the sales territory that you selected (For example, it's **USD** for **North America** but **EUR** for **Europe**).

    d. **Royalty program edition**: The edition of the product you will sell for this royalty program. Choose from the following options:

    * **Standard**
    * **Non-Standard Collector's Edition**
    * **Non-Standard Game of Year**
    * **Non-Standard Digital Disc Expansion**
    * **Non-Standard Limited Edition**
    * **Non-Standard Special Edition**
    * **Non-Standard Starter Packs**
    * **Review Disc** (Europe only)
    * **Hits**

    > [!NOTE]
    > You must wait a certain amount of time after the first retail release of discs before qualifying for certain royalty program editions. For more information, see the [Xbox Publisher Guide](https://aka.ms/xboxpublisherguide).

    e. **Royalty tier**: Choose from 7 different royalty tiers. Refer to your publishing agreement with Microsoft for more information.

    > [!NOTE]
    > Tier 7 isn't available for North America, South America, or Asia.

    > [!IMPORTANT]
    > Refer to your publishing agreement with Microsoft and the [Xbox Publisher Guide](https://aka.ms/xboxpublisherguide) for guidance about moving up or down a royalty tier.

    f. **First 90 days manufacturing request**: The number of discs that you plan to create in the first 90 days of production.

    g. **Notes**: Any notes that you want to pass on to Microsoft. This field is required.

    > [!NOTE]
    > Refer to your publishing agreement with Microsoft for the correct wholesale price, royalty tier, and review disc quantities. If in doubt, speak to your Microsoft contacts.

4. Answer the questions under **Verification**.

    Your royalty program is eligible for the Japan Tier Reduction Incentive Program if the sales territory is set to **Japan**. Likewise, it's eligible for the Asian Language Localization Program if the sales territory is set to **Asia**. You can learn more about both of these programs in your publishing agreement with Microsoft and the [Xbox Publisher Guide](https://aka.ms/xboxpublisherguide).

    Additionally, you can only answer the question about the royalty tier being different from the base game if the **Royalty program edition** is set to something other than **Standard**, **Hits**, or **Review Disc**, and the royalty program isn't eligible for either the Japan Tier Reduction Incentive Program or the Asian Language Localization Program.
   
5. When you've finished configuring your royalty program, select **Save** to save your configuration. 

6. When you're ready to submit the program for approval, select **Submit**.

## Manage royalty programs

You can review the submitted royalty programs on the **Royalty configuration** page.

**Approval status** tells you where in the approval process the royalty program is. If you just submitted a royalty program, it will say **Pending**.

You can **Cancel** a pending royalty program, or you can edit a royalty program by selecting **Edit** in the **Actions** column. This will take you to the **Create new royalty program** form for the royalty program, where you can edit fields. On this page, you'll also see the **Audit history**, which shows who has requested each audit (**Requested by**), the **Status** of the audit, the **Requested date**, and the **Requester notes** (what the requester wrote in the **Notes** field). When you're finished editing, select **Save** to save your edits, and then select **Submit**.
