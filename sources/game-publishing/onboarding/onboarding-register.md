# Step 1: Register for an XBOX developer program

Registering for the ID@XBOX program is the first step in your XBOX onboarding journey. Here, you create your Microsoft account, sign in to the XBOX Onboarding Hub, and choose the ID@XBOX program so you can start your registration.

## Create a Microsoft account for ID@XBOX

Before you register, create a **new personal Microsoft account (MSA)** to use for ID@XBOX. Choose an email address that your studio keeps access to long term, such as a shared studio mailbox, rather than a personal address tied to one team member. You can't use a company MSA to register for ID@XBOX.

To get started, go to [https://account.microsoft.com/](https://account.microsoft.com/).

> [!IMPORTANT]
> Don't use an existing personal MSA that you use for other Microsoft services. A dedicated account keeps your studio's registration separate and easier to manage. You can create an account on the [Microsoft account](https://account.microsoft.com/) page.

## Start your registration

1. Go to the [XBOX Onboarding Hub](https://developer.microsoft.com/games/publish).
2. Select **Get started**.
3. Sign in with the Microsoft account (MSA) you created for ID@XBOX.
4. On the **Choose a program** page, select **ID@XBOX**.

After you select the ID@XBOX program, you're ready to provide details about your studio.

> [!TIP]
> There are no fees to apply to ID@XBOX.
