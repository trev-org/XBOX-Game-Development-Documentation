# Game concepts

[!INCLUDE [reminder](../../includes/managed-creators-only-feature.md)]

Before you can publish an XBOX game that uses full XBOX services, you need an approved game concept.  

## What is a game concept?

Game concepts give Microsoft an overview of your game, including information such as:
 - The developer of the game.
 - The publisher of the game.
 - The expected release date for XBOX platforms, and actual release dates if the game is already released on other platforms.
 - Which platforms the game supports.
 - A description of the game and an overview of its key features.
 - Any supporting materials you can provide, including gameplay videos or trailers.

## How do I submit a new game concept?
Submit all game concepts through the online [XBOX Game Submission Form](https://aka.ms/xboxgsf) in the XBOX Onboarding Hub. If you don't have access to the hub or form, contact your XBOX team to get access.  

Submit the game concept after you have accurate information that's representative of the final product you're publishing. If you need to modify the game concept after you submit it, communicate any changes to your XBOX contacts. If there are significant changes, such as changes to the game features or publishing and distribution plan, you might need to submit a new game concept.

### Free-to-play (F2P) games
You can submit a concept for a free-to-play (F2P) game. F2P games include a base game license that's free to acquire. Unlike trials and demos, users can download and play the free base game indefinitely or to its completion.

Before you submit a game concept for a F2P product, review the F2P game policies and requirements in the XBOX Games Store Policy, available in the [XBOX Publisher Guide](https://aka.ms/xboxpublisherguide).

When submitting a game concept for a F2P product, be sure to select the F2P option when completing the Game Submission Form. After selecting the F2P option, provide the required information in the questions that are presented.

## Next steps
After XBOX reviews your concept, you receive notice of the decision. If XBOX approves the game concept, you receive confirmation of the terms of the concept approval and instructions for product creation and setup. If you don't already have a publishing agreement with Microsoft for the game, one is provided at this stage.

After XBOX approves your concept, you're ready to create the game in Partner Center and request full XBOX services.

> [!NOTE]
> Your publishing agreements with Microsoft contain critical information about the requirements that your game is bound to. Ensure you review your publishing agreements in full. Keep a copy of them available for your reference.
 
For more information about product setup, see [Set up XBOX products in Partner Center](publishing-processes-product-onboarding-and-configuration.md).

If you're planning to release different editions of your game, review the [SKU planning](publishing-processes-sku-planning.md) guidance.
