**XBOX Series X|S** is Microsoft's current-generation console. This path is for teams whose primary target is the console — you want fast loads, high frame rates, and features like Quick Resume that only exist on XBOX hardware.

<Tip>
  **Is this the right path for you?** Pick this if the console is your main target. If you also want a Windows PC version from the same code, use the [XBOX Play Anywhere](/paths/play-anywhere/overview) path. If PC is your primary target, use [Windows & ROG Ally](/paths/windows/overview).
</Tip>

<Note>
  **Before you start:** you should have finished [ID@XBOX onboarding](/onboarding), have the [GDK installed](/gdk/get-started), and have a [Visual Studio project building](/gdk/developing-new-titles). To test on real hardware you'll also need to order a **dev kit** through Partner Center.
</Note>
