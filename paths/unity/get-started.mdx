Before you dive into Unity \+ GDK development, make sure the following are in place. If anything is missing, go back to the [Home](/) guided path.

## Checklist

- **ID@XBOX onboarding complete** — NDA signed, concept approved, Partner Center registered. See [ID@XBOX onboarding](/onboarding).
- **Dev PC ready** — Visual Studio, Windows SDK, and the GDK installed. See [Setup & install](/gdk/get-started).
- **A working Unity project** locally (any recent 2022 LTS or later).
- **Unity XBOX platform add-on** installed via Unity Hub (requires XBOX platform access via ID@XBOX). See [Unity setup](/pc-e2e/engines/unity).
- **Partner Center product** with the appropriate device rows checked.
