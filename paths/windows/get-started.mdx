Before you dive into PC and handheld development, make sure the following are in place. If anything is missing, go back to the [Home](/) guided path.

## Checklist

- **ID@XBOX onboarding complete** — NDA signed, concept approved, Partner Center registered. See [ID@XBOX onboarding](/onboarding). (PC-only titles can use the public GDK, but XBOX services still require program membership.)
- **Dev PC ready** — Visual Studio, Windows SDK, and the GDK installed. See [Setup & install](/gdk/get-started).
- **A GDK project that builds** — either a new title or a sample. See [Build your first title](/gdk/developing-new-titles).
- **Partner Center product** with the **Desktop → Retail** row checked.
- **Handheld test device** (optional) — ROG XBOX Ally or similar, if you're targeting the Handheld Compatibility program.
