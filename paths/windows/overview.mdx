This path is for teams whose game runs on **Windows PC** and Windows-based handhelds (like the **ROG XBOX Ally**). You'll ship through the Microsoft Store, and you can develop and test entirely on your dev PC — no XBOX console needed.

<Tip>
  **Is this the right path for you?** Pick this if PC is your main target. If you also want the same game on XBOX consoles, use [XBOX Play Anywhere](/paths/play-anywhere/overview) instead — one product, both platforms. If you're using a specific engine, check [Unreal](/paths/unreal/overview), [Unity](/paths/unity/overview), or [community engines](/paths/community-engines/overview) first.
</Tip>

<Note>
  **Before you start:** you should have finished [ID@XBOX onboarding](/onboarding), have the [GDK installed](/gdk/get-started), and have a [Visual Studio project building](/gdk/developing-new-titles). If any of that is missing, go back to the [Home page](/).
</Note>
