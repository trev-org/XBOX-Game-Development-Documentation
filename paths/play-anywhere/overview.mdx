This path curates docs for teams building a **cross-device Play Anywhere** title — one purchase runs on both XBOX consoles and Windows PCs with shared saves and entitlements.

<Note>
  **Prerequisites:** you should already have [ID@XBOX access](/onboarding), a [dev PC set up](/gdk/get-started), and a [GDK project building](/gdk/developing-new-titles). If not, start from the [Home](/) guided path.
</Note>
