XBOX should be a place where everyone has fun. Inclusive and accessible games make it possible for more players to play. This section pulls the Microsoft Gaming Accessibility program together with the GDK APIs you use to ship it.

## Where to start

<Steps>
  <Step title="Learn">
    Start with the [Gaming Accessibility Fundamentals learning path](/principles/gaf-info) and the [Gaming and Disability Player Experience Guide](/principles/gadpeg) to understand player experiences.
  </Step>
  <Step title="Design">
    Use the [XBOX Accessibility Guidelines (XAGs)](/principles/xbox-accessibility-guidelines) — 23 best-practice guidelines built with the Gaming and Disability Community.
  </Step>
  <Step title="Implement">
    Use the GDK APIs and services in the table below, and honour system settings via [Speech accessibility user settings](/principles/speech-accessibility).
  </Step>
  <Step title="Validate">
    Request [MGATS](/principles/mgats) for a free evaluation and ship to [XBOX Accessibility Insiders League (XAIL)](/principles/accessibility-resources#connecting-with-customers) for community feedback.
  </Step>
  <Step title="Merchandise">
    Declare [Accessibility feature tags](/principles/accessibility-feature-tags) in Partner Center so players can filter for the features they need.
  </Step>
</Steps>

## Development APIs and services

| Area | API / Service | Platforms |
| --- | --- | --- |
| Subtitles, captions, text display | `XAccessibility` | Windows, XBOX |
| High-contrast mode | `XAccessibility` (`XHighContrastMode`) | Windows, XBOX |
| Real-time voice chat | [Azure PlayFab Party](/gaming/playfab/features/multiplayer/networking/) | Cross-platform |
| Speech-to-text / text-to-speech chat | PlayFab Party STT/TTS | Cross-platform |
| Screen narration | `SpeechAccessibility` | Windows, XBOX |
