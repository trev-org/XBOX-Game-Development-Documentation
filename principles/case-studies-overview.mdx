The XBOX Sustainability Toolkit pilot program has produced case studies from shipping titles across multiple genres and studios. Each demonstrates measurable energy savings with no visible impact on gameplay. Use them as templates for your own efficiency work.

## How case studies are structured

Every case study covers:

1. **Baseline** — power draw before optimization, captured via PIX Power Monitor or a Certification power report.
2. **Technique** — what the studio changed in the title.
3. **Result** — measured power delta and any frame-time or quality impact.
4. **Roll-out** — default-on, opt-in, idle-triggered, or another delivery model.

## Cross-case patterns

Techniques that worked across multiple titles:

1. **Cap menu and lobby frame rate at 30 Hz (or lower)** — nearly invisible to players, large power win.
2. **Reduce internal resolution in non-gameplay screens** — upscale to preserve UI sharpness.
3. **Idle-timer detection** — reduce rendering load when no input received for 30–120 seconds.
4. **Detect controller disconnect** — if no controller, drop the rendering budget.
5. **Enable Dynamic Power States** — single API call, zero-effort win. See [Dynamic Power States](/principles/dynamic-power-states).
6. **2.5D menus** — replace fully-3D menus with 2D backplates plus minimal 3D where needed.
7. **Default power-saving on** — defaults dominate adoption. For Honor moved adoption from 5% (opt-in) to 95% (default-on) with the same feature.
