Use XBOX Title Storage to persist per-user or global blobs in the cloud, and Connected Storage / XGameSave for game saves.

## Storage types

- **Trusted user storage** — server-authoritative writes (via a service-to-service call).
- **Untrusted user storage** — client-writable per-user blobs.
- **Session storage** — scoped to a multiplayer session.
- **Global title storage** — read-only blobs published by your title.
- **Connected Storage (XGameSave)** — fault-tolerant cross-device game saves.
