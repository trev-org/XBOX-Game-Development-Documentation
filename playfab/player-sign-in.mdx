Sign the local XBOX user into PlayFab using `LoginWithXbox` and an XSTSToken from XSAPI.

## Flow

1. Add and sign-in an XBOX user with [`XUserAddAsync`](/reference/xuser).
2. Acquire an XSTSToken via XSAPI for the PlayFab relying party.
3. Call `PlayFabClientAPI::LoginWithXbox` with the XSTSToken.
4. Cache the resulting entity token and `PlayFabId` for subsequent API calls.
5. Refresh the entity token before it expires.

## Tips

- Always reuse the same master account for the same XUID — don't create duplicates.
- For dedicated servers, use server-side `LoginWithServerCustomId` and trust XUIDs only after server-validated XBOX tokens.
