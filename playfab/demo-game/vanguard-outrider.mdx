Vanguard Outrider is a legacy demo game from the PlayFab team. It still works, but it uses older versions of some features.

<Note>
  For an up-to-date look at current best practices and the latest feature set, use [Winter Starfall](/playfab/demo-game/winter-starfall) instead. Treat Vanguard Outrider as an extra reference.
</Note>

## How it differs from Winter Starfall

Vanguard Outrider needs an empty PlayFab title to populate with data. To try it, first [sign up for a free PlayFab account](https://developer.playfab.com/) and create a new title — you can then open Vanguard Outrider from the demo games dropdown on the **My Studios and Titles** page in Game Manager.

## Legacy features used

Vanguard Outrider runs on:

- **Legacy Economy** (Economy v1)
- **CloudScript (classic)**

Both have modern replacements. New titles should use Economy V2 and CloudScript with Azure Functions.
