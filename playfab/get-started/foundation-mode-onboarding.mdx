Follow these steps to get your studio and first title running in Foundation Mode.

## Before you start

You'll need:

- A PlayFab developer account signed in with **Microsoft Entra ID**.
- A game you're shipping (or planning to ship) on Xbox.
- A [Partner Center account](https://developer.microsoft.com/en-GB/games/publish). You can create one during this process.

## Step 1: Request preview access

<Warning>
  Foundation Mode is preview-only right now, and only for **new titles**. Existing titles can't migrate yet.
</Warning>

1. Sign in to [Game Manager](https://developer.playfab.com/) with your Microsoft Entra ID account.
2. On the **My Studios and Titles** page, click the **...** menu on your studio and choose **Studio settings**. You need admin privileges to see the next tab.
   ![Game Manager My Studios page with the three-dots menu open and Studio settings highlighted.](/images/playfab/studio-settings-menu.png)
3. Open the **Preview Features** tab.
   ![Studio Settings page with the Preview Features tab selected, showing the Foundation Mode card.](/images/playfab/preview-features-tab.png)
4. On the **Foundation Mode** card, select **Request access** and fill out the form.
5. Wait for approval. When you're approved, the card shows an **Approved** badge.

## Step 2: Get a Partner Center account

Skip this step if you already have one.

1. Go to the [Xbox developer onboarding hub](https://developer.microsoft.com/en-GB/games/publish).
2. Follow the sign-up flow.
3. Complete account verification.

## Step 3: Create your Foundation Mode title

Once your studio is approved:

1. In [Game Manager](https://developer.playfab.com/), select your studio.
2. Select **New Title**.
3. Enter a title name and pick the studio.
4. Link the title to an existing **Seller ID** and **Product ID** in Partner Center. These auto-fill from your Microsoft Entra ID.
5. Select **Create Title**.

Your title is now running in Foundation Mode with all included features enabled.

## Next steps

Start building:

- Set up player authentication.
- Configure multiplayer services.
- Set up leaderboards.

If you hit a problem during preview, file a support ticket.
