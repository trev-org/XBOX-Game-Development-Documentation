All new PlayFab accounts created after July 27, 2024 must use Microsoft authentication. The legacy PlayFab username/password system is closed to new accounts.

PlayFab supports two flavors of Microsoft sign-in:

- **Microsoft account (MSA)** — personal accounts (@outlook.com, @hotmail.com, etc.).
- **Microsoft Entra ID** (formerly Azure Active Directory) — work or school accounts.

## Sign up with Microsoft

1. Go to [developer.playfab.com](https://developer.playfab.com).
2. Select **Sign up with Microsoft** and follow the prompts.

## Add a Microsoft-authenticated user to your studio

1. In Game Manager, open the studio's **Users** section.
2. Select **Add User**.
3. Enter the required details and choose **Microsoft** as the authentication provider.
4. Select **Add user** to send the invite.

The invitee registers via their Microsoft account.

## Limitations

Microsoft account authentication is per-user. It supports individual sign-in and token exchange, but not groups or Microsoft Graph.
