Two-factor authentication (2FA) adds a device factor to your PlayFab Game Manager sign-in. After you enable it, sign-in also requires a code from an authenticator app on your phone or tablet.

## Set it up

1. Install an authenticator app on your phone. Common choices:
   - [Google Authenticator (iOS)](https://itunes.apple.com/us/app/google-authenticator/id388497605?mt=8)
   - [Google Authenticator (Android)](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2)
2. In Game Manager, open **Dashboard → Account → My Profile**.
3. Check **Enable two-factor authentication**.
4. In your authenticator app, either scan the QR code or type the key manually.
5. The authenticator app displays a 6-digit code.
6. Back in Game Manager, enter the code and select **Save Profile**.

## Sign in with 2FA

1. Sign in to Game Manager with your Microsoft account as usual.
2. When prompted, open your authenticator app and enter the current 6-digit code.

Codes rotate every 30 seconds. As long as you have the device, you can generate a code any time.
