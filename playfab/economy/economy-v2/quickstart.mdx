Set up your first catalog and grant an item to a test player.

## Steps

1. **Enable Economy v2** in Game Manager under **Settings → Economy (V2)**.
2. **Define a content type** — e.g. `Weapon`, `Skin`, `Currency`.
3. **Create a catalog item** at **Engage → Economy → Catalog (V2) → Items → New item**.
   - Set `FriendlyId`, `Title`, `Content type`, `Start date`.
   - Optionally add price (virtual currency or real money) and tags.
4. **Publish** the item.
5. **Grant to a player** using the [AddInventoryItems](https://learn.microsoft.com/rest/api/playfab/economy/inventory/add-inventory-items) API (server or CloudScript).
6. **Read the player's inventory** from your client with [GetInventoryItems](https://learn.microsoft.com/rest/api/playfab/economy/inventory/get-inventory-items).
