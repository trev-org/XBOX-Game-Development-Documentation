---

Economy v2 enforces the following limit categories:

- **Catalog limits** — maximum items per title, maximum tags per item, maximum properties per item.
- **Inventory limits** — maximum stacks per collection, maximum collections per player.
- **Rate limits** — requests per second per title and per player on catalog and inventory APIs.
- **UGC limits** — payload size per item, media count per item.

Refer to the source [`limits.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/economy-monetization/economy-v2/limits.md) for the current numeric values — they change independently of this doc.

If you expect to bump a hard limit, raise a support ticket well before launch.
