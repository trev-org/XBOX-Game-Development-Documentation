Manage Economy v2 settings under **Settings → Economy (V2)** in Game Manager.

## Common settings

- **Enable Economy v2** — required before catalog/inventory APIs work for the title.
- **Content types** — declare allowed content types (`Weapon`, `Skin`, `Currency`, `Bundle`, `UGC`).
- **Default marketplace platforms** — which platform mappings each catalog item can carry.
- **UGC** — enable UGC, moderation rules, tag policy.
- **Currencies** — per-currency caps, initial grants, recharge schedules.
- **Deep link platforms** — allowed platform values for catalog deep links.

Settings are versioned; changes take effect immediately after Save.
