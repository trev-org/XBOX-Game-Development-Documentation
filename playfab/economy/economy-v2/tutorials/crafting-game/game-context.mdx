This tutorial series builds a small crafting game to demonstrate Economy v2 features end-to-end: currencies, container bundles, drop tables, and inventory updates.

## The game

- Players harvest resource items (wood, iron, gems).
- Combine resources at a crafting bench to produce weapons.
- Weapons are separate catalog items with per-instance durability stored in `DisplayProperties`.

Each step of the series is a page under this group.
