Set up dependencies for the crafting sample:

- Install the PlayFab C# SDK (or your platform's SDK).
- Install .NET 8 (for local server logic) or your engine of choice.
- Store your title ID and developer secret key in local user secrets, not source control.
- Verify connectivity with `LoginWithCustomID` against a dev title.
