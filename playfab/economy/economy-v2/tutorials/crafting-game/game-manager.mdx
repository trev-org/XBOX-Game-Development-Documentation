---

Create the crafting game's catalog:

1. **Currencies** — `GOLD` (soft) and `GEMS` (hard).
2. **Resources** — `WOOD`, `IRON`, `GEM` as consumables.
3. **Weapons** — `SWORD`, `BOW`, `STAFF` as content type `Weapon` with `DisplayProperties` schema for durability.
4. **Bundles** — `STARTER_PACK` containing a mix of resources and 100 GOLD.

Publish and note the `FriendlyId` of each item for later use.
