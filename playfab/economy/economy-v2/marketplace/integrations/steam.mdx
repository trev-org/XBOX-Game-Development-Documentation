---
title: "Steam integration"
sidebarTitle: "Steam"
description: "Link Economy catalog items to Steam microtransactions."
---

Steam microtransactions are represented as **Steam Item Definitions** or Steamworks in-app purchases. Link the Steam product/definition ID to the catalog item.

1. Configure Steamworks microtransactions or item definitions.
2. Add a **Steam** marketplace mapping to the catalog item using that ID.
3. Configure your app's Web API key so PlayFab can validate Steam transactions.

Source: [`marketplace-integrations/steam.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/economy-monetization/economy-v2/marketplace/marketplace-integrations/steam.md).
