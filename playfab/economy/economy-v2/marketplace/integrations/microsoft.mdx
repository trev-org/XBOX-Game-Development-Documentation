---
title: "Microsoft Store integration"
sidebarTitle: "Microsoft Store"
description: "Link Economy catalog items to Microsoft Store products."
---

Create an in-app product in Partner Center, then link its Store ID to the catalog item's Microsoft marketplace mapping.

1. Create the product in **Partner Center → Add-ons**.
2. Grab the **Store ID** and the **Product kind** (durable, consumable, subscription).
3. In Game Manager, open the catalog item and add a marketplace mapping for **Microsoft** with the Store ID.
4. Test purchase and redemption end-to-end with a sandbox account.

See also: [Store integration for Microsoft Store (with XStore)](/playfab/microsoft-store).
