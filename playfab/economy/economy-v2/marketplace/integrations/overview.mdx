Each catalog item can carry per-platform **marketplace mappings** — the platform product ID that represents the item on that storefront.

## Supported platforms

- [Microsoft Store](/playfab/economy/economy-v2/marketplace/integrations/microsoft)
- [Apple App Store](/playfab/economy/economy-v2/marketplace/integrations/apple)
- [Google Play](/playfab/economy/economy-v2/marketplace/integrations/google)
- [Steam](/playfab/economy/economy-v2/marketplace/integrations/steam)

Setup involves creating the product on the platform's developer portal, then referencing its product ID from the catalog item's marketplace mapping and (optionally) deep link.
