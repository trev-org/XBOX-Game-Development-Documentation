A legacy store is a curated list of catalog items with optional per-store price overrides. Stores are per-catalog-version and per-title.

## APIs

- `GetStoreItems` — read a store as a player.
- `SetStoreItems` — authoring (admin).
- `PurchaseItem` — spend virtual currency for a store item.

## Common patterns

- Featured store on the main menu.
- Segment-specific discount stores.
- Time-limited event stores.
