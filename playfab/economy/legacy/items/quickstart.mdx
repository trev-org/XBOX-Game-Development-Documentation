---
title: "Items quickstart (legacy)"
sidebarTitle: "Quickstart"
description: "Create a virtual currency, add a catalog item, and grant it."
---

1. Add a virtual currency in **Engage → Economy → Currencies**.
2. Add a catalog item in **Engage → Economy → Catalogs**.
3. Grant it: [`GrantItemsToUser`](https://learn.microsoft.com/rest/api/playfab/server/player-item-management/grant-items-to-user).
4. Read it back on the client: [`GetUserInventory`](https://learn.microsoft.com/rest/api/playfab/client/player-item-management/get-user-inventory).
5. Consume with [`ConsumeItem`](https://learn.microsoft.com/rest/api/playfab/client/player-item-management/consume-item).
