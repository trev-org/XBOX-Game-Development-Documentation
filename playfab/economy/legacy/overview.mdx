Legacy Economy is the original PlayFab Economy: catalogs of items, virtual currencies, stores, and trading. It's still supported for titles that shipped on it, but new titles should build on [Economy v2](/playfab/economy/economy-v2/overview).

## Building blocks

- **Items** — [Items](/playfab/economy/legacy/items/overview)
- **Stores** — [Stores](/playfab/economy/legacy/stores/overview)
- **Trading** — [Trading](/playfab/economy/legacy/trading/overview)
- **Tutorials** — [Tutorials](/playfab/economy/legacy/tutorials/currencies)

## When to migrate

- If you plan to add UGC, bundles, subscriptions, or real-money prices, migrate to v2.
- Migration is non-trivial: expect to remap items and re-issue inventories.
