Content & Config writes cover updates to title data, catalog, stores, files, and other title-level configuration. Writes bill per operation.

## Server APIs

- `SetPublisherData`
- `SetTitleData`
- `SetTitleDataAndOverrides`
- `SetTitleInternalData`

## Entity APIs

- `UpdateFiles` / `DeleteFiles` / `FinalizeFileUploads` / `AbortFileUploads`
- `SetObjects`

- `AddNews`
- `AddVirtualCurrencyTypes`
- `CreatePlayerSharedSecret` / `DeletePlayerSharedSecret` / `SetPlayerSecret` / `UpdatePlayerSharedSecret`
- `DeleteContent`
- `DeleteStore` / `SetStoreItems` / `UpdateStoreItems`
- `DeleteTitle`
- `RefundPurchase`
- `SetPublishedRevision`
- `SetPublisherData`

- `SetupPushNotification`
