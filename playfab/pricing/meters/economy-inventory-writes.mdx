Economy v2 inventory writes cover all writes against player inventories in Economy v2.

## Inventory write APIs

- `AddInventoryItems`
- `DeleteInventoryCollection`
- `DeleteInventoryItems`
- `ExecuteInventoryOperations`
- `ExecuteTransferOperations`
- `PurchaseInventoryItems`
- `SubtractInventoryItems`
- `TransferInventoryItems`
- `UpdateInventoryItems`

For the full up-to-date list, see the [Economy API reference](/playfab/economy-monetization/economy).
