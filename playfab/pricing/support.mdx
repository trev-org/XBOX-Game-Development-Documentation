Support is tiered by account plan. Higher tiers unlock more channels and faster response times.

| Channel | What it covers | Available to |
| --- | --- | --- |
| **Documentation** | API reference, tutorials, samples, guides | Everyone |
| **Discord community** | Peer support, service status, product discussion | Everyone |
| **Account Help** | Account access, billing, plan changes, sales | All PlayFab accounts |
| **Support tickets** | Technical issues, implementation help, bugs | Standard plan and above |
| **Emergency escalations** | 24/7 on-call for critical outages | Premium and Enterprise |

## Documentation

Open to the public. Start at the [PlayFab documentation site](/playfab/overview).

## Discord community

Free, community-run product discussion. No PlayFab account required.

Join the [Microsoft Game Dev Discord](https://discord.com/invite/msftgamedev) and opt into the PlayFab channel during onboarding.

## Account Help

Use for non-technical questions — account access, billing, plans, or sales.

1. Sign in to [developer.playfab.com](https://developer.playfab.com).
2. Open the studio-level ellipsis menu (`...`).
3. Select **Account Help**.
4. Fill in the Problem Type and Sub-Type, describe the issue, and submit.

Expect a response within three business days.

<Note>
  The legacy **Contact Us** form on PlayFab.com is deprecated. For login issues, use the Microsoft Entra ID self-service recovery flow.
</Note>

## Support tickets

Available on **Standard** plans and above. Use for technical help, implementation questions, or bug reports.

1. Sign in to [developer.playfab.com](https://developer.playfab.com).
2. Go to the **Title Overview** page for the affected title.
3. Select the **?** icon in the top-right nav.
4. Choose **Contact Us** and complete the form.

Response within one business day.

If you recently upgraded, ticket submission unlocks when the plan change takes effect at the start of the next billing period. See [Account upgrades](/playfab/pricing/account-upgrades).

## Emergency escalations

Available on **Premium** plans and above. Use only for high-impact, service-affecting outages.

<Warning>
  Emergency escalations page an on-call engineer. Use sparingly.
</Warning>

1. Sign in to [developer.playfab.com](https://developer.playfab.com).
2. Go to the **Title Overview** page and open the **?** menu.
3. Select **Contact Us** and fill in the Problem Type and Sub-Type.
4. The **Emergency On-Call Alert** option appears if you qualify. Select **Yes** to submit.

To unlock this channel, see [Account upgrades](/playfab/pricing/account-upgrades).
