Every new PlayFab title starts in **Development Mode**. In this mode, your usage doesn't count toward any billable meters — up to a fixed set of limits.

<Note>
  Development Mode is being replaced by **Foundation Mode** as of March 11, 2026. For new titles, [use Foundation Mode](/playfab/get-started/foundation-mode-onboarding). Titles that ship to an Xbox storefront get Foundation Mode as part of their platform agreement.
</Note>

<Warning>
  Move your title out of Development Mode before releasing. Development Mode titles are capped at 1,000 unique users — after that, new player accounts fail to create.
</Warning>

## How to launch a title

When you're ready to go live, use the **Launch** button on the Game Overview page. See [Title launches](/playfab/pricing/title-launches).

## How Development Mode appears in billing

Only live titles count against your plan's included resources. Example:

| Title | Mode | Meter consumption | Billed? |
| --- | --- | --- | --- |
| Fun Game | Live | 1M PlayStream events | Yes |
| Fun Game 2 | Development | 100k PlayStream events | No |

## Studio limits

| Limit | Amount |
| --- | --- |
| Titles in Development Mode | 10 |

## Title limits

| Limit | Amount |
| --- | --- |
| Unique users | 1,000 |
| PlayStream events | 1 million |
| Telemetry events | 1 million |
| Profile reads | 5 million |
| Profile writes | 1 million |
| Profile storage | 2 GB |
| Entity statistics reads | 5 million |
| Entity statistics writes | 1 million |
| Entity statistics storage | 100 definitions, 1 version |
| Entity leaderboard reads | 5 million |
| Entity leaderboard writes | 1 million |
| Entity leaderboard storage | 50 definitions, 10,000 rows, 1 version |
| Content and configuration reads | 20,000 |
| Content and configuration writes | 15,000 |
| Content and configuration storage | 2 GB |
| CloudScript execution time | 20,000 GB-s |
| CloudScript total executions | 200,000 |
| Insights | Performance Level 1 |

**Unique users** = total players ever created in the title (not MAU or DAU).

For the latest limits, see [PlayFab pricing](https://www.playfab.com/pricing).
