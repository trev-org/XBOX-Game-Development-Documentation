PlayFab data and analytics helps you close the telemetry loop:

- **Ingesting data** — PlayStream events, telemetry, telemetry keys, sessions.
- **Exporting data** — Data Connections to Azure Data Explorer, Blob, sampling, partitioning.
- **Learning with data** — Data Explorer, Reports, Trends, Churn prediction.
- **Acting on data** — Actions & Rules, Schemas, Webhooks, Scheduled Tasks.
- **Privacy & compliance** — GDPR player-data export and delete.

Source: [Data and analytics](https://github.com/microsoft/playfab-docs/tree/master/sources/playfab-docs/data-analytics)
