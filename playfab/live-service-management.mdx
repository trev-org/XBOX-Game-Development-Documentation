PlayFab's live service management features help you operate a live game after launch. Use them to update configuration remotely, segment your player base, run experiments, and communicate with your players.

## Game Manager

The [Game Manager](/playfab/live-service-management/game-manager) web portal is a centralized hub where studio members build, configure, and operate their games. It provides developer authentication with roles and access permissions to keep game operations secure.

## Game configuration and title data

PlayFab lets you manage game configuration and title data remotely. Update game settings without shipping a patch, so players get changes right away.

- [Game server configuration](/playfab/live-service-management/game-server-configuration) — server-side configuration and the Entity Model.
- [Title Data](/playfab/live-service-management/title-data) — key/value settings you can change without a client update.

## Player segmentation and experimentation

PlayFab provides tools for grouping your player base and targeting specific groups for configuration changes and A/B testing.

- [Segments](/playfab/live-service-management/segments) — group players by behavior or attributes.
- [Experiments](/playfab/live-service-management/experiments) — run split tests on player segments to determine the best outcomes.

## Title communications

Communicate with your players using push notifications, emails, and message-of-the-day pop-ups. See [Title communications](/playfab/live-service-management/title-communications).

## Throttling and extensions

- [Throttling](/playfab/live-service-management/throttling) — PlayFab's per-title rate limits and how to design around them.
- [Extensions](/playfab/live-service-management/extensions) — add-ons, CloudScript, and Azure Functions.
