The Experiments overview page categorizes experiments by status: **Running**, **Scheduled**, **Drafted**, **Completed**.

- **Running / Scheduled** appear in a timeline view with name, variant count, start/end date, and a near-real-time player count (last 8 hours) for running experiments.
- **Drafted** appear in the same _In-progress_ tab, below the timeline.
- **Completed** appear in the _Completed_ tab with the same metadata.

## Managing an experiment

Select an experiment's ellipsis (`…`) to act on it. Actions vary by state:

- **Draft:** Edit, Start, Delete, Clone as draft.
- **Scheduled:** Edit, Cancel schedule, Clone as draft.
- **Running:** Stop, Clone as draft.
- **Completed / Stopped:** Delete, Clone as draft, View scorecard.

Select the experiment name to open the details and scorecard page.
