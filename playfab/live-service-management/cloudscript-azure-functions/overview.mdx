**CloudScript using Azure Functions** runs your PlayFab custom logic as serverless Azure Functions, in the language of your choice (C#, JavaScript/TypeScript, Python, PowerShell, Java). Integration with Visual Studio Code and Azure gives you real IDE-quality debugging.

Compared to legacy JavaScript CloudScript:

- **More languages** — pick what fits your team.
- **Strong typing** — e.g. C# with the PlayFab SDK.
- **Full Azure ecosystem** — CosmosDB, Storage, Key Vault, Event Grid, etc.
- **Better debugging** — breakpoints in VS Code or Visual Studio.

Use Azure Functions CloudScript for any new work.
