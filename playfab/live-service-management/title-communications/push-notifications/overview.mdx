Push notifications give you a channel to send immediate customized messages to a player's device — even when the player isn't currently running the game.

Common uses:

- Tell a user they received a message.
- Announce an in-game update.
- Prompt a player to take an action.

Used judiciously, push notifications can improve retention by drawing players back at key moments before churn. PlayFab lets you send unlimited push notifications to any number of devices at no charge.

<Note>
  Tell players up front how you'll use push notifications, before they see the system OS prompt. Explaining the value increases opt-in rates dramatically.
</Note>
