Get started with PlayFab by creating your account, studio, and first title in Game Manager.

<Warning>
  As of 8/31/2022, Game Manager no longer supports browsers using TLS 1.0 or 1.1. Any connection must use TLS 1.2 or higher. If you can't reach Game Manager, verify your browser supports TLS 1.2 and has it enabled.
</Warning>

## Create a PlayFab account

On the [PlayFab sign-up screen](https://developer.playfab.com), create a PlayFab-specific account or use your Microsoft account to sign in.

After signing in, PlayFab prompts you for contact information and studio information. You can rename the studio later.

## Create your first game

At a minimum, enter a name for your game. You can also specify:

- Title genre
- Monetization mode
- Target marketplaces
- Player mode

These properties feed the Benchmark comparisons feature so PlayFab can show a finer-grained view of benchmark data. You can set them later.

## Your studios and titles

When the account, studio, and first game are created, Game Manager opens the dashboard for the new title. On subsequent sign-ins it opens **My Studios and Titles** instead. Select a title to open its dashboard.

Many API calls require a **TitleId** — the short string ID displayed under your title name in the dashboard.
