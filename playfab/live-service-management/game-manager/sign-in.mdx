<Warning>
  On April 30, 2025, Game Manager retired support for [legacy PlayFab authenticated](https://developer.microsoft.com/en-us/games/articles/2024/05/changes-to-developer-authentication-for-playfab/) developer accounts. Users must migrate their accounts to a Microsoft account. Learn more about the [self-service migration tool](https://developer.microsoft.com/en-us/games/articles/2025/02/playfab-developer-account-self-service-migration-tool-now-available/).
</Warning>

Game Manager lets you sign in with either a Microsoft account or a legacy PlayFab authenticated account. If you can't reach your studios and titles, you might be signing in with the wrong account type.

<Note>
  It's possible to have both a PlayFab authenticated account and a Microsoft account using the same email. If you don't see the studios and titles you expect, try the other sign-in method.
</Note>

## Microsoft account

Select **Sign in with Microsoft** and complete the sign-in flow. You're redirected to **My Studios and Titles**.

## Legacy PlayFab authenticated account

Select **Have a non-Microsoft account and need to migrate?**, then enter your PlayFab email and password. This begins the migration process.

<Note>
  Using **Sign in with Microsoft** with a Microsoft account that isn't associated with a PlayFab account creates a brand-new developer account with a new studio and title.
</Note>

## Still can't sign in?

[Contact PlayFab support](https://playfab.com/contact/) and include the email and sign-in method you used.

## FAQ

### What is a PlayFab authenticated account and why migrate to a Microsoft account?

A PlayFab authenticated account is the legacy account system using email and password. New PlayFab developer account creation was disabled on July 29, 2024, to improve security. Migrating to a Microsoft account lets you use a single identity across every Microsoft Gaming developer portal.

### I don't see my studios and titles after migrating

Your account might be under a different Microsoft account. Try:

1. Signing out and signing in with a different Microsoft account.
2. Using a private browser so cached Windows credentials aren't reused.

If you still don't see your content, [contact us](https://playfab.com/contact/).

### After migration my PlayFab account is disabled and I can't sign into my Microsoft account

If you see `AccountDisabled` on the legacy PlayFab flow, or "You aren't authorized to view this page" on the Microsoft flow, [contact us](https://playfab.com/contact/) with both account details.

### I clicked "Migrate later" but now want to migrate

1. Sign into your legacy PlayFab authenticated account.
2. Select your profile icon in the upper-right and choose **My Profile**.
3. Select **Migrate now** and follow the prompts.
