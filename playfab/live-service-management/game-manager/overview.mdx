This article introduces Game Manager, the PlayFab developer portal, and helps you get familiar with the portal experience.

## What is Game Manager?

Game Manager is a web-based dashboard that provides access to your studios and the tools to manage your games. It's your go-to destination for managing studio and game configuration. Most PlayFab tutorials show you how to complete tasks in Game Manager and through API calls.

Game Manager offers a comprehensive backend suite so you can pick the services that suit your game.

Use Game Manager to invite teammates, grant them full or partial access, manage secret keys, configure encryption settings, and set client app trust levels.

## The Game Manager interface

When you sign in, Game Manager opens the **My Studios and Titles** page, which lists every studio and title you can access. Select a title to manage it.

A title is divided into four major views:

- **Title Overview** — recent and overall performance of your title.
- **Build** — foundational elements and tools to configure your game.
- **Engage** — tools to connect with players.
- **Analyze** — monitor and act on player behavior.

See [Game Manager reference](/playfab/live-service-management/game-manager/reference) for details on each view.

## Recommended browsers

Use **Google Chrome** or **Microsoft Edge** for the best experience. Both are tested and optimized for Game Manager.
