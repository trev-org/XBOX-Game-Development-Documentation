PlayFab developer secret keys let your title make PlayFab Admin and Server API calls. A secret key (also called a developer key) is strongly coupled with a PlayFab title.

Use the **Secret Keys** page in Game Manager to create, delete, disable, and set expirations for keys. This lets you rotate keys safely and grant temporary access.

<Warning>
  Never include a developer secret key in a client build you ship to customers. Doing so exposes your title to abuse.
</Warning>

## Open the Secret Keys page

1. Sign in to Game Manager.
2. Select your title.
3. Select the gear icon in the upper-right corner.
4. Choose **Title settings**, then the **Secret Keys** tab.

The page shows each key's **Status**, **Name**, **Value**, and **Expiration** (if any), with options to **Delete** keys. Select a key to rename, enable, disable, or set an expiration for it. Every title starts with a default key.

## Rotate keys

1. Select **New Secret Key**.
2. Enter a **Name** and (optionally) an expiration date.
3. Update your code to use the new key.
4. Disable the old key: select it, then check **Disable** on the **Edit Secret Key** page.
5. Select **SAVE SECRET KEY**.

<Warning>
  If your keys are compromised, rotate them immediately.
</Warning>

This flow is zero-downtime and you can safely roll back each step until you delete the old key:

- After step 1, if there's an issue, delete the new key — no one is using it yet.
- At step 2, both keys are active so you can roll code forward or back safely.
- At step 3, you can re-enable the old key while you fix any lingering dependency.

When the process is done, you don't need to delete the old key. Deleting a key is permanent and irrevocable.

**Expiring keys** are useful for temporary access. For example, give a contractor a key that expires when their work ends. Extend the expiration if they need more time.

## IP allowlist

IP allowlists ensure a title secret key can't be used from outside the IPs you trust. Each secret key can carry its own list of IPv4 or IPv6 addresses (or CIDR ranges).

When an allowlist is configured, privileged calls (Server and Admin APIs) made with that key are accepted only from source IPs on the list. Calls from other IPs are rejected even if the key itself is valid. Every change to a key, including allowlist edits, is captured in the PlayStream `secret key changed` event.

**Supported formats:**

- IPv4 and IPv6 addresses (for example, `203.0.113.7` or `2001:db8::1`).
- CIDR ranges in either family (for example, `203.0.113.0/24` or `2001:db8::/32`).

**Configure an IP allowlist:**

1. In Game Manager, go to **Title Settings \> Secret Keys**.
2. Edit or create a secret key.
3. Toggle **Enable IP allowlist**.
4. Add your egress IPs or CIDR ranges, one per line.
5. Select **Save**.

<Warning>
  Double-check the list before saving. An incorrect entry blocks every IP that isn't on the list, which can lock your services out of the Server and Admin APIs.
</Warning>
