---

Install the module and log in:

```powershell
Install-Module -Name PlayFabMultiplayer
Connect-PlayFabTitle -TitleId <YourTitleId>
```

Upload a build:

```powershell
New-PlayFabBuild -BuildName "my-build" -ContainerImageName "myrepo/server:latest" `
  -VmSize "Standard_D2as_v4" -RegionConfiguration @{ EastUs = @{ StandbyServers = 2; MaxServers = 10 } }
```

Allocate:

```powershell
Request-PlayFabMultiplayerServer -BuildId <BuildId> -PreferredRegions @("EastUs") -SessionId (New-Guid)
```
