## Build lifecycle

`Uploading` → `Deploying` → `Deployed` → `Deleted`.

## Build-region lifecycle

Each region attached to a build reports its own state: `Deploying`, `Deployed`, `Unhealthy`. Regions can be added/removed independently.

## Game-server lifecycle

`Initializing` → `StandingBy` → `Active` → `Terminating`. Servers in `StandingBy` are eligible for allocation; `Active` servers host a match; `Terminating` are shutting down.

Allocation only picks `StandingBy` instances. Ensure your standby \> 0 in every active region.
