PlayFab commits to communication SLAs for Multiplayer Servers:

- **Planned maintenance** — advance notice via Game Manager notifications and email.
- **Incident notifications** — during active incidents.
- **Deprecations** — API and feature deprecations with migration windows.

Check [aka.ms/playfabstatus](https://aka.ms/playfabstatus) for live status.
