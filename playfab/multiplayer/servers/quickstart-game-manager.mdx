---
title: "Game Manager quickstart"
sidebarTitle: "Quickstart: Game Manager"
description: "Upload a build and allocate a server through the UI."
---

1. Package your server as a zipped Windows container or Linux container image, or a Windows process build.
2. In Game Manager → Multiplayer → Servers → **New build**.
3. Configure regions, VM size, and standby counts.
4. Wait for the build to deploy — a build only becomes allocatable once each region has healthy VMs.
5. Click **Request server** to allocate a test session.

Source: [`quickstart-for-multiplayer-servers-api-features-through-game-manager.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/servers/quickstart-for-multiplayer-servers-api-features-through-game-manager.md).
