Enable **crash dump collection** on a build's region config to capture minidumps whenever the server process crashes. Dumps upload alongside logs when the agent tears down the VM.

## Sizing

- **Mini dumps** — small, stack \+ module list.
- **Full dumps** — include heap; multi-GB. Bill impact for storage.

Use full dumps sparingly (a specific bug hunt), mini dumps as a default.
