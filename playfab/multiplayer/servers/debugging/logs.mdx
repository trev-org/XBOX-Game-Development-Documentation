At server shutdown, the agent zips up any files in the `PF_SERVER_LOG_DIRECTORY` path and uploads them to PlayFab. Retrieve them from Game Manager → **Multiplayer → Servers → Build → Servers → \[instance\]** or via the `GetMultiplayerServerLogs` API.

## Guidance

- Write to `PF_SERVER_LOG_DIRECTORY`; anything outside is discarded.
- Rotate large logs during the match; the agent copies the current file at shutdown.
- Ship structured logs (JSON per line) so post-mortem queries are grep-able.
