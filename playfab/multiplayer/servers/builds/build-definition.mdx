Build definitions declare:

- **Metadata** — name, tags.
- **Asset references** — file names, mount paths.
- **Game certificates** — optional certs mounted into VMs.
- **Ports** — name, protocol, container port.
- **Region config** — VM size, standby count, max servers, dynamic-standby settings.
- **Container image** (Linux) or **Windows executable command line**.
