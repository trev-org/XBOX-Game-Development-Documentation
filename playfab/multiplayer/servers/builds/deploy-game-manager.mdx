---
title: "Deploy a build using Game Manager"
sidebarTitle: "Deploy (Game Manager)"
description: "Point-and-click build deployment for quick iteration."
---

1. **Multiplayer → Servers → New build**.
2. Upload asset, set start command, VM size.
3. Add regions with initial standby counts.
4. Save. Watch the **Overview** tab until every region reports `Deployed`.
5. Optionally assign the build to an alias for zero-downtime rollout.

Source: [`deploy-using-game-manager.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/servers/deploy-using-game-manager.md).
