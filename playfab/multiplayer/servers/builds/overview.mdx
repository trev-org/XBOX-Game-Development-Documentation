---

A **build** is one uploaded server-binary bundle plus its config: start command, VM size, container image (Linux) or asset (Windows), network ports, and per-region standby settings.

Builds are immutable. Publish a new build to change binaries or config. Use a **build alias** so clients don’t hard-code build IDs.
