A build packages everything the agent needs to run your server:

- **Assets** — zipped server binaries (Windows) or a container image (Linux).
- **Start command** — how to launch the binary.
- **Ports** — declared game ports mapped through Azure networking.
- **VM size** — CPU/RAM tier.
- **Regions** — which Azure regions host instances.
- **Standby / max** — scaling knobs per region.

Source: [`build-overview.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/servers/build-overview.md).
