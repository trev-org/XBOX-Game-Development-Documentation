A Windows Multiplayer Servers VM is a stripped Server Core image. Missing DLLs are a top cause of failed builds.

## Recommended techniques

- Copy the server binary to a fresh Server Core VM and run it. Watch for `Missing DLL` errors.
- Use **Dependency Walker** or **Dependencies** (Lucas G. project on GitHub) to enumerate imports.
- Use `procmon` with the `LoadImage` filter while the server starts.
- Include the Visual C\+\+ Redistributable and DirectX runtime in your asset zip.
