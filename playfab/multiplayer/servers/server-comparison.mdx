Side-by-side of major hosting choices:

| Option | Managed | Standby scaling | Matchmaking integration | Best for |
| --- | --- | --- | --- | --- |
| PlayFab Multiplayer Servers | Yes | Built-in | Native | Session-based multiplayer games |
| Azure Kubernetes Service | Partial | Custom | Custom | Persistent world servers, complex topologies |
| Bare Azure VMs | No | You build it | You build it | Very custom hardware or networking |
| First-party (Xbox Live) | Yes | N/A | Xbox Live only | Xbox-only titles using MPSD |

Source: [`server-comparison.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/servers/server-comparison.md).
