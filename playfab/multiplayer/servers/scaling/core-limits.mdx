Multiplayer Servers VMs count against your Azure subscription's core quota. Common causes of failed scaling:

- Subscription core limit reached in a region.
- VM family quota reached (e.g. `Dv4` cores in `EastUs`).
- Regional capacity constraint (rare, transient).

## Check and raise

1. Open Azure Portal → **Subscriptions → Usage \+ quotas**.
2. Filter by region \+ VM family used by the build.
3. Request an increase via the portal; approval can take days.

Raise limits well before launches and tournaments — an emergency request on the day of an event is a bad time to start.
