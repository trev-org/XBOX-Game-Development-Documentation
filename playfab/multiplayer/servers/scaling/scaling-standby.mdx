Each build region has a **StandbyServers** target and a **MaxServers** ceiling.

- Standby = pre-warmed VMs waiting for allocation. Should cover expected spikes in the next minute or two.
- Max = hard ceiling. Requests beyond this return `AllocationFailed` unless dynamic-standby raises it.

## Rules of thumb

- Start standby at ~10% of expected concurrent sessions per region.
- Watch allocation latency — if it climbs above ~1 second, raise standby.
- Watch idle-standby cost — if servers sit unused for \>30 minutes, standby is too high.
