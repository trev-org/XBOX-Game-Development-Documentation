The **MPS Unity** sample is a Unity project configured as a headless dedicated server:

- Uses the PlayFab GSDK Unity package.
- Reports readiness at load-scene complete.
- Accepts allocations and starts the match on the server.
- Publishes shutdown callbacks.

Build it as a Linux server (`Server Build` \+ `Linux`) or Windows server (headless subsystem) and upload as a normal Multiplayer Servers build.

Source: [`mps-unity.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/servers/mps-unity.md).
