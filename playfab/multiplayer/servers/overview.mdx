**PlayFab Multiplayer Servers** hosts your dedicated server binaries on Azure VMs, auto-scaled per region.

## What you get

- **Global regions** — deploy the same build across Azure regions.
- **Standby VMs** — pre-warmed capacity for fast allocation.
- **GSDK** — lightweight SDK your server links against to report state and heartbeat.
- **Metrics & logs** — per-server telemetry in Game Manager.
