A guided path for first-time users:

1. Enable Multiplayer Servers.
2. Build a hello-world server (`Windows Runner` sample is fastest — see [samples](/playfab/multiplayer/servers/samples)).
3. Zip the binary \+ GSDK DLLs.
4. In Game Manager, create a new build with a small VM (`Standard_D2as_v4`).
5. Wait for `Deployed` in one region.
6. Allocate from the Test panel; confirm the returned IP and port work.

Source: [`create-your-first-server.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/servers/create-your-first-server.md).
