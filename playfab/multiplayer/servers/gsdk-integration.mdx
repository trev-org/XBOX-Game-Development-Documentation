The **GSDK** is the bridge between your server binary and the Multiplayer Servers agent. It:

- Reports server state (`Initializing` → `StandingBy` → `Active` → `Terminating`).
- Delivers allocation details (initial players, session config).
- Sends heartbeats so the agent knows the server is alive.
- Publishes shutdown/maintenance hooks.

## Basic loop

1. On startup, call `Start()` — blocks on config from the agent.
2. Transition to `ReadyForPlayers()` when initialization completes; server enters **StandingBy**.
3. On `OnAllocation` callback, receive session config; enter **Active** and begin the match.
4. On match end, call `Shutdown()` and exit cleanly.
