Multiplayer Servers enforces per-title quotas across:

- Total build count.
- Concurrent build regions.
- Max servers per region.
- Concurrent allocations per second.
- Asset upload total size.

Default values suit development; production titles often need increases.

## Request more

- Open a support ticket via Game Manager.
- Include your title id, region(s), and forecasted concurrent servers.
- Request at least a week before you need the change.
