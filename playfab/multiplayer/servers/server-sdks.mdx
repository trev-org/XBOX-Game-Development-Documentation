GSDK is available for every common server stack:

- **C\+\+** — native Windows and Linux.
- **C# / .NET** — for .NET-based dedicated servers.
- **Java** — useful for Minecraft-style servers.
- **Go** — for Go-based backends.
- **Unity / Unreal** — wrapper packages that expose GSDK to the engine.

All SDKs implement the same lifecycle: `Start`, `ReadyForPlayers`, `OnAllocation`, `Shutdown`. Pick the one that matches your engine or runtime.
