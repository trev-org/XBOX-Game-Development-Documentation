Common terms:

- **Build** — versioned bundle of server binaries and config.
- **Build alias** — stable named pointer to one or more builds with weights.
- **Region** — Azure datacenter hosting instances of a build.
- **Standby** — pre-warmed instances waiting for allocation.
- **Active** — an instance currently hosting a match.
- **Allocation** — the act of selecting a `StandingBy` instance for a session.
- **GSDK** — Game Server SDK; the API your server uses to talk to the agent.
- **Agent** — the PlayFab process on each VM that manages your server.
- **Session** — one match; instantiated from an allocation.
