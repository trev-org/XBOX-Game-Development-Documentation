sidebarTitle: "Endpoint transmission"
description: "How Party messages route."
---

Each connected device has one or more **endpoints**; messages address a set of endpoints and pick a reliability class. Broadcast to all endpoints, filter to teammates, or unicast to a single peer.

Source: [`concepts-endpoint-transmission.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/networking/concepts-endpoint-transmission.md).
