sidebarTitle: "Multiple networks"
description: "Joining multiple Party networks."
---

A client can join more than one network simultaneously — e.g. one for the friends party, one for the current match. Each network has its own endpoints and chat controls.

Source: [`concepts-multiple-networks.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/networking/concepts-multiple-networks.md).
