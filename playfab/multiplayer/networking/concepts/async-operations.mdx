Party is event-driven: every long-running operation completes by posting a state change. Pump state changes each frame with `PartyManager::StartProcessingStateChanges` / `FinishProcessingStateChanges`.

Source: [`concepts-async-operations.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/networking/concepts-async-operations.md).
