On Xbox Live titles, MPSD sessions represent the group; Party carries voice/data. Store the Party network descriptor in an MPSD property so joining players can bootstrap the Party network.

Source: [`using-mpsd.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/networking/using-mpsd.md).
