---

Every rule has a **weight**. When the matcher scores candidate groupings, rules with higher weights dominate. Use weights to encode business priorities:

- Latency and region rules — heaviest (players hate lag).
- Skill rule — middle.
- Cosmetic attribute rule (e.g. same game mode preference) — lightest.

Rule weights combine with rule expansion: as time passes, the _effective_ weight of a rule drops, letting the matcher accept looser matches.
