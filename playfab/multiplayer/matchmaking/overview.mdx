**PlayFab Matchmaking** groups players into balanced matches using configurable **queues**.

## Concepts

- **Queue** — a named configuration: min/max players per match, rule set, expansion policy.
- **Ticket** — an active request to be matched, holding one or more members.
- **Rule** — constraint on how to combine tickets (skill difference, latency, region, attribute equality).
- **Match** — the result: a set of tickets grouped, with a session id.
- **Backfill** — add new players to an in-progress match.
