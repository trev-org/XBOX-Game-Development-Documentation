The Unity multiplayer package wraps the C/C\+\+ SDK with idiomatic C# types under the `PlayFab.Multiplayer` namespace. Highlights:

- `PlayFabMultiplayer` — static entry point, event handlers.
- `Lobby` and `LobbyMember` — lobby state.
- `MatchmakingTicket` and `Match` — matchmaking state.

Source: [`unity-multiplayer-api-reference.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/lobby/unity-multiplayer-api-reference.md).
