Lobbies expose two property bags:

- **Lobby properties** — owner-writable, visible to all members.
- **Member properties** — each member writes their own, visible to all.

Any property change is broadcast via real-time messages so every subscriber sees the update in near-real time.

Use properties for lobby-scoped settings (map, mode, ready state) and per-member state (character choice, ping estimate).

Source: [`lobby-properties.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/lobby/lobby-properties.md).
