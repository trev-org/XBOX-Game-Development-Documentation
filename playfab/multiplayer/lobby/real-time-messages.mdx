title: "Lobby real-time messages"
sidebarTitle: "Real-time messages"
description: "Push events for lobby state changes."
---

Members receive push events for:

- Member joined/left.
- Owner changed.
- Lobby properties updated.
- Member properties updated.
- Lobby deleted.

The multiplayer client SDK exposes these via callbacks; the REST API surfaces them through subscribing entities. Combine with [Real-time messages](/playfab/multiplayer/real-time-messages/overview) to receive events over a persistent connection.

Source: [`lobby-real-time-messages.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/lobby/lobby-real-time-messages.md).
