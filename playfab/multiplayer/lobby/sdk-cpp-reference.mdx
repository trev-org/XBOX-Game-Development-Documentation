The C/C\+\+ multiplayer SDK is delivered as a single header and static lib. Top-level modules:

- **PFMultiplayer.h** — handle lifetime, state-change pump.
- **PFLobby.h** — lobbies and members.
- **PFMatchmaking.h** — tickets, matches, backfill.
- **PFEntityKey.h** — entity key helpers.

See the full symbol list in the source: [`playfabmultiplayerreference-cpp.md`](https://github.com/MicrosoftDocs/playfab-docs/blob/main/playfab-docs/multiplayer/lobby/playfabmultiplayerreference-cpp.md).
