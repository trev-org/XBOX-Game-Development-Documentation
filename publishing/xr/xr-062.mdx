## Intent

Achievement names and descriptions are customer-facing copy that ships in every language the title supports and is visible on the Xbox profile forever. XR-062 requires that this copy meets a quality bar and doesn't include content that's inappropriate on the Xbox surface.

## Applies to

Every title with declared achievements.

## Requirement

Achievement names and descriptions **MUST**:

- Be **clear** — the name conveys the accomplishment; the description explains what the customer did to earn it (or, if secret, an appropriate hint).
- Be **localized for every declared supported language** (see [Supported languages](/publishing/supported-languages)). No English strings appearing in a French listing.
- Follow **official Microsoft naming standards** for platform references (see [XR-022](/publishing/xr/xr-022)).
- Be **free of profanity** in every language variant.
- Be **free of spoilers** where the achievement is marked secret. If the customer must earn a story-critical unlock, the description should hint rather than reveal.
- Match the **shipped achievement behavior** — if the achievement description says "Complete 100 races," 100 races must earn it.
- Include a **valid unlocked-state image** (see [DP 2013 achievements](/publishing/dp2013-achievements) for schema).

Achievement names and descriptions **MUST NOT**:

- Include third-party trademarks without authorization.
- Include self-referential debug text (`Achievement_37`, `TODO: NAME`).
- Include obscene, discriminatory, or harassing content in any language.
- Include content that materially exceeds the title's declared age rating.

## Tested scenarios

- Verify every achievement has a name and description in every declared supported language.
- Verify no placeholder text (`[LOC]`, `TODO`, `Achievement N`).
- Verify achievement unlock behavior matches the description.
- Spot-check localizations for machine-translation artifacts.

## Best practices

- **Have a copy editor pass** every language, not just a machine translation.
- **Write descriptions before implementing the achievement** — forces clarity on what the trigger actually is.
- **Keep names short** — platform UI truncates long names.
- **Version achievement copy** carefully; renaming a live achievement is possible but confusing to customers.
