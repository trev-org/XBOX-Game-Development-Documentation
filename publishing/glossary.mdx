A reference for the terms used throughout the Publishing docs. Terms link to the page that covers them in depth.

## A

**Add-on** — Downloadable content (consumable, durable, durable-with-package, or bundle) sold under a base game. See [Add-ons](/publishing/add-ons).

**ACB** — Australian Classification Board. Regulates age ratings in Australia. See [Ratings](/publishing/ratings).

## B

**Base game** — The primary product a customer purchases. Add-ons and bundles reference the base game.

**Branch** — A per-module isolated set of edits in Partner Center that can be published independently of the Main branch. See [Branches](/publishing/branches).

**BVT** — Build Verification Test. Scripted pre-cert test pass. See [Console BVT](/publishing/console-bvt-guide) and [PC BVT](/publishing/pc-bvt-guide).

**Bundle** — A Store product that grants entitlements to multiple constituent products. See [Bundles](/publishing/bundles).

## C

**Cert Bypass** — A program letting qualifying live-ops titles ship updates without a full XR cert pass. See [Cert bypass program](/publishing/cert-bypass-program).

**Certification (Cert)** — Microsoft's compliance and quality gate against the XBOX Requirements. See [Certification](/publishing/certification).

**CERO** — Computer Entertainment Rating Organization (Japan). Requires direct submission for Japan releases.

**ClassInd** — Brazil's age rating body.

## D

**Data Platform** — The XBOX services stack version. **DP 2013** covers older Xbox Live; **DP 2017** covers current GDK services.

**Deviation** — A formal request that the test team accept a specific XR failure with justification.

**Disc Certification** — A separate cert submission for the exact disc image sent to the replicator. See [Discs](/publishing/discs).

**DLC** — Downloadable content. Umbrella term for post-launch add-on content.

## E

**Edition** — A distinct SKU of a title (Standard, Deluxe, Ultimate). Members of the same [Product group](/publishing/product-groups).

**ESRB** — Entertainment Software Rating Board (US, Canada). Covered by IARC digitally.

## F

**Final Certification** — The mandatory cert pass required to publish to RETAIL. See [Submit to certification](/publishing/submit-to-certification).

**Flight** — A package release to a specific audience rather than all owners. See [Package management](/publishing/how-to-package-management).

**FMA** — Failure Mode Analysis. The report attached to a failing cert submission. See [XR FMA](/publishing/xr-fma).

**Free-to-use** — A game with a base price of \$0. See [Trials](/publishing/how-to-trials).

## G

**Game Preview** — Sell an in-development title on the Microsoft Store with early-access framing. See [XBOX Game Preview](/publishing/xbox-game-preview).

**Game setup** — The Partner Center module where you configure product basics: type, device families, sandboxes. See [Game setup](/publishing/game-setup).

**GDK** — Game Development Kit. Microsoft's SDK for XBOX and PC development.

**GRAC** — Game Rating and Administration Committee (Korea). Requires direct submission for Korea releases.

## H

**Hidden product** — A product not returned in Store search or browse, only reachable by direct URL or promo code. See [Visibility](/publishing/how-to-visibility).

## I

**IARC** — International Age Rating Coalition. The Partner Center questionnaire that produces provisional ratings across multiple bodies. See [Ratings](/publishing/ratings).

**ID@Xbox** — Microsoft's indie publishing program. See [Managed programs](/publishing/managed-programs).

**Insider Program** — XBOX Insider Program, used for opt-in beta / flight audiences. See [XBOX Insider Program](/publishing/xbox-insider-program).

## M

**Managed Creator** — A publisher with a direct commercial relationship with Microsoft (as opposed to a Creators Program self-service publisher). Most first-party and third-party publishers are Managed Creators.

**MGATS** — Microsoft Gaming Accessibility Testing. Advisory accessibility test pass. See [MGATS](/publishing/mgats).

**Modular submission** — Partner Center's model of publishing changes to individual modules independently. See [Review & publish](/publishing/modular-submission).

**MSIXVC** — Microsoft's PC package format (Windows PC equivalent of XVC).

## O

**Optional Certification** — Advisory cert pass that doesn't publish. See [Optional submissions](/publishing/optional-submissions).

## P

**Partner Center** — Microsoft's web portal for Microsoft Store product configuration and publishing.

**PEGI** — Pan-European Game Information. European age rating body. Covered by IARC digitally.

**Play Anywhere** — A cross-buy program where one purchase entitles both Xbox and PC. See [Managed programs](/publishing/managed-programs).

**Product group** — A container of related SKUs that share ownership dedup and upgrade logic. See [Product groups](/publishing/product-groups).

**Promo code (Token)** — A Microsoft Store redemption code granting a specific product. See [Promo codes](/publishing/promo-codes).

## R

**Reparenting** — Moving a product between Partner Center accounts. See [Reparenting](/publishing/reparenting).

**RETAIL sandbox** — The production sandbox. Required for Final Cert and live customers.

**Rich Presence** — Xbox Live localized strings describing what a player is doing.

**RTM** — Release To Manufacture. The point of contract sign-off on a disc image and artwork. See [Approve discs (RTM)](/publishing/approve-discs-for-manufacture).

## S

**Sandbox** — Isolated XBOX services environment. See [Sandboxes](/publishing/sandboxes).

**Season Pass** — A durable add-on granting future DLC. See [Add-ons](/publishing/add-ons).

**SKU** — Stock-keeping unit. A distinct Store product. See [SKU planning](/publishing/sku-planning).

**Smart Delivery** — One purchase delivers the correct package per device generation.

**Supplemental Info** — The submission-time information you provide to the test team. See [Supplemental info](/publishing/supplemental-info).

**Sub-publishing** — A publisher ships a title on behalf of a developer. See [Sub-publishing](/publishing/sub-publishing).

## T

**Test account** — An Xbox Live account scoped to a sandbox with simulated entitlements. See [Sandboxes & test accounts](/publishing/how-to-sandboxes-test-accounts).

**Trial** — A free version of the game that upsells. See [Trials](/publishing/how-to-trials).

## U

**UGC** — User-generated content.

**USK** — Unterhaltungssoftware Selbstkontrolle (Germany). Digital ratings via IARC; longform required for discs.

## X

**XBOX Requirement (XR)** — An individual compliance rule tested during certification. See [XBOX requirements](/publishing/xbox-requirements).

**Xbox Insider Program** — See Insider Program.

**XStore** — The Microsoft Store commerce SDK for querying entitlements, purchasing, and consuming products. See [XStore deep dive](/publishing/xstore-deep-dive).

**XVC** — Xbox Virtual Container. The Xbox console package format.
