XBOX offers the option to test Betas and Game Previews against a reduced set of XBOX Requirements, because players expect these products to be unfinished. This page lists the exact XRs that apply for cert — everything else is advisory until the title exits Beta / Preview and enters Final Cert.

For the Preview commercial model see [XBOX Game Preview](/publishing/xbox-game-preview). For the full cert bar see [Certification](/publishing/certification) and [XBOX requirements](/publishing/xbox-requirements). For the full change log see [XR change history](/publishing/xr-change-history).

## Betas

Microsoft must approve **all** beta products and validate them for Submission Checks. In addition, products made available to consumers are subject to and validated against the XRs listed below.

**All Open Betas must be certified before they can be released.** For **Closed Betas**, the distribution type and audience size determine whether a Beta XR review is required before release:

| Closed Beta type | Audience size | Beta XR review required? |
| --- | --- | --- |
| Managed by the Publisher | Fewer than 10,000 users | No (but subject to Microsoft review) |
| Managed by the Publisher | 10,000 or more users | **Yes** |
| Managed by the XBOX Insiders Program | Fewer than 50,000 users | No (but subject to Microsoft review) |
| Managed by the XBOX Insiders Program | 50,000 or more users | **Yes** |

Beta products are generally treated as **separate from the full game**:

- All XRs are applicable when only the full game is prepared for release.
- Exceptions filed for the beta release **do not carry over** to the full game unless also filed under the full game.
- In limited scenarios (such as Free to Play) where a beta migrates directly to the full title, the title must undergo a full certification pass and **all XRs are applicable**.

## Game Preview

Game Preview titles require certification and adherence to the XRs listed below. Although the number of requirements is reduced, this **may not shorten the overall timeframe** required for updates. When a title exits the Game Preview program it must undergo a full certification pass and **all XRs are applicable**.

## Applicable XRs for Beta and Game Preview

Beta and Game Preview titles must meet the following XRs for certification. A blank cell means the XR does not apply to that combination of platform and release type.

  **XR-133 does not apply to PC Beta or Game Preview.** Local storage write limitations are a console-only concern.
</Note>

<Warning>
  Any XR **not** listed above is advisory during Beta / Game Preview but becomes a ship-blocker the moment the title transitions to Final Cert. Plan your compliance work accordingly.
</Warning>

## Beta vs Game Preview at a glance

| Aspect | Beta | Game Preview |
| --- | --- | --- |
| Purpose | Public test of a near-complete title | Sell an in-development title on the Store |
| Sold on Store? | Sometimes (paid beta) | Yes — with clear Preview labeling |
| Duration | Short (days / weeks) | Long (months / years) |
| Product type in Partner Center | Standard product with beta flag | **Game Preview** product type |
| Cert bar | Beta-reduced XR set (above) | Preview-reduced XR set (above) |
| Exit path | Ends when the full title ships | Transition to full product type when 1.0 cert passes |
