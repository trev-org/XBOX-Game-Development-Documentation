Use this checklist in the two weeks before your target Final Cert submission. If any item is red, resolve it before submitting.

## Product configuration

- Product name is reserved and matches the intended shipping title.
- Content type, device families, and generation targeting are correct in [Game setup](/publishing/game-setup).
- Included products, product groups, and identity are correct.
- All add-ons that ship with the base game are configured and linked — see [Add-ons](/publishing/add-ons).
- Franchise / Game Hub grouping is set if applicable — see [Franchise hubs](/publishing/franchise-hubs).

## Store listing

- Per-language listings complete for every release language.
- Screenshots, hero art, and trailers meet current asset specs.
- Accessibility features are declared accurately — see [Properties](/publishing/properties).
- Privacy policy URL is live and reachable.

## Pricing and availability

- Base price set per market.
- Release date and markets set in [Pricing](/publishing/pricing).
- Pre-orders configured if applicable — see [Pre-release](/publishing/pre-release).

## Ratings

- IARC questionnaire complete and provisional ratings issued.
- Region-specific ratings (CERO, USK longform, GRAC, ACB longform) issued for every market you plan to release in — see [Ratings](/publishing/ratings).
- Physical longform ratings uploaded for any disc SKU.

## Packages and services

- Final Cert candidate package uploaded and passes Submission Validator with zero errors.
- Console BVT and PC BVT pass locally on all supported device families.
- Top failing XR self-test complete — see [Top failing tests](/publishing/xr-top-failing).
- XBOX services (achievements, stats, multiplayer, Rich Presence) published to the RETAIL sandbox.
- Day-one update planned and staged if applicable.

## Certification submission

- Supplemental Info form complete with test accounts, DLC grants, and known issues.
- Correct branch selected in Partner Center.
- Submission type confirmed (Final Certification for release).
- Release option chosen (auto-publish, hold for manual, or scheduled).

## Disc (if applicable)

- Disc addendum executed.
- Disc image passes Disc Certification.
- Artwork approved per region.
- Royalty tier submitted and approved.
- RTM sign-off complete — see [Approve discs for manufacture](/publishing/approve-discs-for-manufacture).
- Manufacturing order placed and lead time confirmed — see [Order discs](/publishing/order-discs).
