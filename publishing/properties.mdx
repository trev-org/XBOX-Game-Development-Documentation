The **Properties** module configures product-wide metadata that isn't tied to a specific package, Store listing locale, or price. Properties feed the Store PDP, the Store's category browse, discovery filters, and legal/compliance disclosures.

Properties is split into two subsections in Partner Center: **Basic info** and **Technical capabilities**. Each is documented in detail on its own page.

## Sections

<CardGroup cols={2}>
  <Card title="Basic info" icon="circle-info" href="/publishing/properties-basic-info">
    Category, subcategory, support contact, privacy policy, and product tags.
  </Card>

  <Card title="Technical capabilities" icon="microchip" href="/publishing/properties-technical-capabilities">
    System requirements, input methods, hardware feature declarations, and accessibility.
  </Card>
</CardGroup>

## When Properties is required

Properties must be complete before a product can pass [Certification](/publishing/certification). Missing or invalid values in either subsection put the module in a red state and block [Review and publish](/publishing/modular-submission).
