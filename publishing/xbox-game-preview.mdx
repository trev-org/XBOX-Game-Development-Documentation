**XBOX Game Preview** is Microsoft's early-access program. It lets you list, sell, and iterate on a title that isn't feature-complete, with clear labeling so customers know what they're buying.

## Who qualifies

Game Preview is not automatic — it requires approval from your Microsoft representative. Typical criteria:

- Playable core loop with meaningful ongoing content updates planned.
- Clear roadmap and communication plan for the Preview period.
- Reasonable stability (crash rate below the retail bar is expected, but not "unplayable").
- Commitment to a Preview → full release transition within a defined window (commonly 12–24 months).

<Warning>
  Titles that ship as Game Preview and then never leave Preview status damage customer trust and Microsoft's willingness to approve future Preview titles from the same publisher. Have a real transition plan.
</Warning>

## Configuration

In Partner Center:

1. **Product type** — select **Game Preview** in [Game setup](/publishing/game-setup) at product creation. This adds the Game Preview badge to your Store listing and enables specific messaging.
2. **Store listing** — include a Preview-specific description block that sets expectations about scope, missing features, and update cadence. See [Store listing](/publishing/store-listing).
3. **Certification** — Game Preview titles still pass [Certification](/publishing/certification), but some XRs are relaxed to reflect the in-development nature (for example scope of feature completeness).
4. **Pricing** — you can price at your target full-release price or discount for Preview — either is allowed as long as it's disclosed. See [Pricing](/publishing/pricing).

## Transitioning to full release

<Steps>
  <Step title="Confirm full-release readiness">
    You must pass the **standard Final Cert bar** (all XRs, not the Preview-relaxed set) before you can leave Preview.
  </Step>
  <Step title="Update Partner Center">
    In Game setup, change the product type from Game Preview to the standard product type.
  </Step>
  <Step title="Submit Final Cert">
    Submit a fresh Final Certification pass for the release-candidate build. See [Submit to certification](/publishing/submit-to-certification).
  </Step>
  <Step title="Communicate the launch">
    Update Store listing copy and imagery to remove Preview messaging, and coordinate marketing for the "1.0 launch" moment.
  </Step>
</Steps>
