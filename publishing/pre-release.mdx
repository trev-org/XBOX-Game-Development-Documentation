Manage pre-release activities — announcements, pre-orders, betas, demos, and review embargoes — from Partner Center.

## Common pre-release flows

- **Coming Soon listing** — publish a placeholder store page with announce art.
- **Pre-orders** — configure pre-order pricing, pre-order incentives, and bonus add-ons.
- **Beta / playtest** — distribute via [XBOX Insider Program](/publishing/xbox-insider-program) or limited Partner Center flights.
- **Demo / trial** — publish a separate trial product or use the XStore time-limited trial.
- **Review code distribution** — via the press code program in Partner Center.
