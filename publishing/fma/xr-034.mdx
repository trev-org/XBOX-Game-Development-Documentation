See also [XR-037 reference](/publishing/xr/xr-037). This page is fix-oriented for streaming install initial-play failures.

## Common FMA text patterns

- **"Title crashed at initial play marker; required additional chunk"** — title referenced content not in the initial chunks.
- **"Initial play marker declared too small"** — the title's actual runnable-state requires more than declared.
- **"Title hung at loading screen with initial-play install"** — waiting on content not yet installed.
- **"Advertised install size does not match streaming layout"** — chunk manifest incorrect.

## Common root causes

| Symptom | Root cause | Fix |
| --- | --- | --- |
| Crash at initial play | Initial chunks don't contain everything needed to reach a playable state | Move required assets into chunk 0; adjust manifest |
| Hang at loading | Sync wait on a not-yet-installed chunk | Check chunk availability before referencing content |
| Wrong install size | Manifest doesn't match actual layout | Regenerate manifest from the packaging tool |

## Fixing

- Audit the **initial play marker** — what's the customer-visible playable state? Everything to reach it must be in chunk 0.
- Add **runtime chunk-availability checks** before referencing content in later chunks.
- **Regenerate the chunk manifest** with your packaging tool and verify against runtime consumption.
