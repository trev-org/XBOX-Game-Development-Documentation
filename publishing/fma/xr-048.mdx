[XR-048 reference](/publishing/xr/xr-048) is the reference. This page is fix-oriented.

## Common FMA text patterns

- **"Title defaulted to English despite account preferred language"** — profile language ignored.
- **"Mature content shown to child account with strict filter"** — content filter bypassed.
- **"Pricing shown in dev region despite account region"** — region ignored.

## Fixing

- Load **preferred language** at title start; use it as the default unless the customer overrides.
- Query **content filters** at content-gate time.
- Use **account region** for market-specific behavior, not the console region.
