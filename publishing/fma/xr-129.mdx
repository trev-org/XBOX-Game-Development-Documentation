# XR-129: Intelligent Delivery Content Management

## FMA scenario severities

See the [XR-129 reference](/publishing/xr/xr-129) for the underlying certification requirement.

### 129-01 Intelligent Delivery of Language Packs

| Scenario | Severity | Platform |
| --- | --- | --- |
| No current scenario. | Not Relevant (-4) |  |
| No current scenario. | Very Minor (1) |  |
| The title doesn't provide an in-title language option and the user must change the Xbox system language to initiate the language pack install. | Minor (2) | Xbox One, Xbox Series |
| No current scenario. | Moderate (6) |  |
| The title doesn't install the expected language pack based on the console language setting. | Critical (12) | Xbox One, Xbox Series |
| Selecting a different language from a menu option doesn't install the correct language pack. | Critical (12) | Xbox One, Xbox Series |
| No current scenario. | Catastrophic (22) |  |

**Notes**

- Suggested probability to be discussed with the MS Lead when necessary.
