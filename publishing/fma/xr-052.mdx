# XR-052: User State and Title Save Location, Roaming, and Dependencies

## FMA scenario severities

See the [XR-052 reference](/publishing/xr/xr-052) for the underlying certification requirement.

| Scenario | Severity | Platform |
| --- | --- | --- |
| No current scenario. | Not Relevant (-4) |  |

| The title stores global data as per-user data. | Moderate (6) | Xbox One, Xbox Series |
