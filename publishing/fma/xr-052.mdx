[XR-052 reference](/publishing/xr/xr-052) is the reference. This page is fix-oriented.

## Common FMA text patterns

- **"Save corrupted after \[event\]"** — partial write.
- **"Cloud save did not roam to console B"** — save in title-owned location.
- **"Save from account A visible under account B"** — wrong XUID association.
- **"Save conflict silently overwritten"** — no conflict resolution.

## Fixing

- Write saves **atomically**: write to temp, fsync, rename.
- Store user state in **Connected Storage** keyed to signed-in XUID.
- Present a **conflict resolution UI** when local and cloud saves diverge.
- Reset save state on `XUserChangeEvent` — don't carry across accounts.
- **Version save format** and support migration.
