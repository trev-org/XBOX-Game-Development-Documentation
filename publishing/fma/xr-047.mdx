[XR-047 reference](/publishing/xr/xr-047) is the reference. This page is fix-oriented.

## Common FMA text patterns

- **"Presence shown for account with 'no one' presence setting"** — privacy bypass.
- **"Activity feed included restricted target"** — wrong scope.
- **"Stale profile shown after target changed privacy"** — no invalidation.

## Fixing

- Query profile data **at display time**, not aggressively cached.
- Honor privacy per-field: presence, activity, achievements-visible-to-friends, real name.
- Refresh on privacy-change events.
