## Common FMA text patterns

- **"Session state desynced between members"** — authoritative-state model broken.
- **"MPSD session persisted after all members left"** — no session cleanup.
- **"Host migration failed; remaining members orphaned"** — no host election path.
- **"Session state overwritten by stale write"** — race condition on MPSD writes.

## Common root causes

| Symptom | Root cause | Fix |
| --- | --- | --- |
| Desync | Multiple writers to MPSD without arbitration | Use an authoritative host or MPSD-arbitrated writes |
| Ghost session | No cleanup on session end | Remove members and delete session on natural end |
| Failed host migration | No election path or too-strict timeout | Implement host election; timebound the migration |
| Race on write | Optimistic writes without version checks | Use MPSD's version tags for compare-and-swap semantics |
