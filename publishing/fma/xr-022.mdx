# XR-022: Official Naming Standards

## FMA scenario severities

See the [XR-022 reference](/publishing/xr/xr-022) for the underlying certification requirement.

### 022-01 Official Naming Standards

| Scenario | Severity | Platform |
| --- | --- | --- |
| Incorrect term used instead of that which is listed in the Official Naming Standards with no user impact. Examples, but not limited to: Xbox 360 iconography for A, B, X, Y used for Xbox One buttons; 'Input control device' instead of 'Xbox Controller'; 'Gamer tag' instead of 'Gamertag'; 'Xbox network user' instead of 'Xbox network profile'; 'Controller' or 'Gamepad' instead of 'Xbox Controller'; 'Xbox Live Gold subscription' instead of 'Xbox Game Pass Essential membership'; 'Press Any Key' at the IIS. | Not Relevant (-4) | Xbox One, Xbox Series, Windows |
| A competitor platform is mentioned as part of legal text, or ways which don't actively promote them, their features and functionality. | Not Relevant (-4) | Xbox One, Xbox Series, Windows |
| The title uses Xbox network terminology to describe non-Xbox network title features which aren't proprietary terms and won't cause user confusion (for example, Achievements). | Not Relevant (-4) | Xbox One, Xbox Series, Windows |
| The title displays D-pad imagery which resembles a competitor's D-pad. | Not Relevant (-4) | Xbox One, Xbox Series |
| Non-Xbox button iconography is displayed in the controls options. For example, to select a DUALSHOCK 4 setup, as users can connect these to PCs. | Not Relevant (-4) | Windows |
| The title uses an Xbox 360 controller image instead of an Xbox controller image. | Not Relevant (-4) | Windows |
| Incorrect term used instead of that which is listed in the Official Naming Standards which won't cause confusion. | Very Minor (1) | Xbox One, Xbox Series, Windows |
| The title displays "Press Start" in a highly visible area of the title. | Very Minor (1) | Xbox One, Xbox Series |
| The vibration feature is referred to as 'rumble'. | Very Minor (1) | Xbox One, Xbox Series |
| Incorrect term used instead of that which is listed in the Official Naming Standards with minor user impact. Examples, but not limited to: 'XBox' instead of 'Xbox'; 'Xbox network ID' instead of 'profile'; 'Xbox One main menu' instead of 'Home'; 'Xbox 360' instead of 'Xbox One' referenced in a low visibility area of the title; capitalizing official terms inappropriately such as Xbox NETWORK, XBOX NETWORK; 'Joystick' instead of 'Left stick' or 'right stick'. | Minor (2) | Xbox One, Xbox Series, Windows |
| The title uses the text L and/or R to describe the triggers and/or bumpers instead of RB/LT, etc. which would otherwise cause confusion. | Minor (2) | Xbox One, Xbox Series |
| The title refers to the Xbox network as Xbox Live. | Minor (2) | Xbox One, Xbox Series, Windows |
| Incorrect term used instead of that which is listed in the Official Naming Standards with moderate user impact. Examples, but not limited to: Xbox 360 Back/Start iconography used for the Xbox View/Menu buttons. | Moderate (6) | Xbox One, Xbox Series, Windows |
| The title uses an Xbox 360 controller image instead of an Xbox controller image. | Moderate (6) | Xbox One, Xbox Series |
| Incorrect term used instead of that which is listed in the Official Naming Standards with notable user or brand impact. | Critical (12) | Xbox One, Xbox Series, Windows |
| The title refers to gamerscore as Points. | Critical (12) | Xbox One, Xbox Series, Windows |
| Xbox One is referred to as Xb1, Xbone, XB One etc. | Catastrophic (22) | Xbox One, Windows |
| References to competitor platforms in a promotional manner, their features or functionality. Examples, but not limited to: HD Rumble; PSN™ ID, Nintendo Network ID, Steam ID, Steam Account Name; competitor controller buttons. Exceptions — references to competitor platforms as part of Terms and Conditions (i.e. not actively promoting them), references to products that aren't available to purchase on the Xbox Store, competitor logos used as network identifiers for cross-network users. | Catastrophic (22) | Xbox One, Xbox Series |
| Competitor terminology used to refer to a component of the system or component of a peripheral where it's clear that an equivalent term in the terminology list should be used. E.g. PSN ID is referred to where gamertag suits the context. Note: it's allowed to let users select non-Xbox button iconography in the controls options. For example, to select a DUALSHOCK 4 setup, as users can connect these to PCs. | Catastrophic (22) | Windows |

**Notes**

- As of January 2022, Xbox terminology has been updated to use the term Xbox network vs. Xbox Live when making reference to the network. Titles released prior to January 2022 are exempt from this requirement.
- "PSN" is a registered trademark or trademark of Sony Interactive Entertainment Inc.
- "DUALSHOCK" is a registered trademark or trademark of Sony Interactive Entertainment Inc.
