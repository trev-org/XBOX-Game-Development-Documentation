# XR-046: Display Name and Gamerpic

## FMA scenario severities

See the [XR-046 reference](/publishing/xr/xr-046) for the underlying certification requirement.

### 046-01 Display Name and Gamerpic

| Scenario | Severity | Platform |
| --- | --- | --- |
| A gamertag isn't updated when shown as part of metadata for that user's associated UGC (for example, the listed creator). | Not Relevant (-4) | Xbox One, Xbox Series, Windows |
| No current scenario. | Very Minor (1) |  |
| The title displays the user's gamerpic, but the gamerpic is displayed incorrectly in low visibility areas. The gamerpic is accompanied by the gamertag which is both clearly visible and accurate. | Minor (2) | Xbox One, Xbox Series, Windows |
| The title correctly displays a user's gamertag but is split between two lines. | Minor (2) | Xbox One, Xbox Series, Windows |
| In a non-core or low visibility area of the title, the title doesn't correctly display all 15 characters of any gamertag. | Moderate (6) | Xbox One, Xbox Series, Windows |
| The gamertag doesn't show some of the Unicode characters correctly (including the auto-generated suffix) when using a modern gamertag. (Log as an ION) | Moderate (6) | Xbox One, Xbox Series, Windows |
| The title displays the user's gamerpic, but the gamerpic is displayed incorrectly in high visibility areas. The gamerpic is accompanied by the gamertag which is both clearly visible and accurate. | Moderate (6) | Xbox One, Xbox Series, Windows |
| In core high visibility areas of the title, the title doesn't correctly display all 15 characters of any gamertag. | Critical (12) | Xbox One, Xbox Series, Windows |
| The title displays the user's gamerpic, but the gamerpic is displayed incorrectly throughout the title. The gamertag doesn't accompany the gamerpic. | Critical (12) | Xbox One, Xbox Series, Windows |
| The title displays a gamertag or gamerpic different from that of the selected Xbox network user. | Critical (12) | Xbox One, Xbox Series, Windows |
| The title doesn't display any of the required characters of a user's modern gamertag correctly. | Critical (12) | Xbox One, Xbox Series, Windows |
| No current scenario. | Catastrophic (22) |  |

**Notes**

- In betas, the gamertag isn't required to be displayed (for example, active user indication), but if the title does implement it then it needs to adhere to this XR.
