## Common FMA text patterns

- **"Friends list did not update after add/remove"** — no refresh on social change events.
- **"Blocked user appeared in friends list"** — filter not applied.
- **"Friend list included non-friends"** — wrong query scope.

## Common root causes

| Symptom | Root cause | Fix |
| --- | --- | --- |
| Stale list | No refresh on `XblSocialAddedRelationshipChangeSubscription` | Wire the subscription; refresh on event |
| Blocked appears | Filter not applied post-query | Filter blocked XUIDs after query |
| Wrong scope | Called `GetPeople` or wrong API | Use the correct social API scoped to the friend relationship |
