This page covers creating the three product types you'll use most: a **base game**, an **add-on**, and a **bundle**.

## Create a base game

<Steps>
  <Step title="Confirm concept approval">
    You cannot create a game without an approved concept. See [Game concepts](/publishing/game-concepts).
  </Step>
  <Step title="Reserve the game name">
    Reserve the title as described in [Game name](/publishing/game-name).
  </Step>
  <Step title="Create the product">
    In Partner Center, open **Games → New product → Game**. Select the reserved name.
  </Step>
  <Step title="Choose the product group">
    Either create a new [product group](/publishing/product-groups) or add the new SKU to an existing one (for editions of an existing title).
  </Step>
  <Step title="Complete Game setup">
    Configure content type, device families, sandboxes, and identity in [Game setup](/publishing/game-setup).
  </Step>
</Steps>

## Create an add-on

<Steps>
  <Step title="Open the parent product">
    Navigate to the base game the add-on belongs to.
  </Step>
  <Step title="Add-ons → New add-on">
    In the product's left nav, open **Add-ons** and click **New add-on**.
  </Step>
  <Step title="Choose the add-on type">
    Consumable, developer-managed consumable, durable, durable-with-package, or store-managed consumable. See [Add-ons](/publishing/add-ons).
  </Step>
  <Step title="Reserve the add-on name and product ID">
    Both must be unique within the parent game's context.
  </Step>
  <Step title="Complete configuration">
    Set Store listing, Pricing, and (for durable-with-package) upload the add-on package. See [XStore deep dive](/publishing/xstore-deep-dive).
  </Step>
</Steps>

## Create a bundle

<Steps>
  <Step title="Games → New product → Bundle">
    In Partner Center, open the new-product flow and select **Bundle**.
  </Step>
  <Step title="Reserve the bundle name">
    Bundles follow the same name reservation rules as games.
  </Step>
  <Step title="Add contents">
    In [Product relationships](/publishing/product-relationships), add the constituent products.
  </Step>
  <Step title="Configure Store listing, Pricing, Availability">
    Bundles need their own Store listing copy and price. See [Bundles](/publishing/bundles).
  </Step>
</Steps>
